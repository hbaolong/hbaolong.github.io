《老人与海》专业名词

文/韩宝龙

2026年11月13日 23时07分52秒

这份清单明显是《老人与海》一类出海捕鱼语境。下面按“钓鱼出海”相关性筛出，已去掉专名和太泛的词：

1. 鱼与海洋生物

albacore / albacores（长鳍金枪鱼）、bonito（鲣鱼）、barracudas（梭鱼）、broadbill（剑鱼）、dorado（鲯鳅）、eels（鳗鱼）、mako（灰鲭鲨）、marlin（马林鱼）、sharks（鲨鱼）、shovelnose（铲吻鲨一类）、squid（鱿鱼，常作饵）、shrimp / shrimps（虾，饵/渔获）、tuna / tunas（金枪鱼）、turtle / turtles（海龟）、loggerheads（赤蠵龟）、porpoises（海豚）、plankton（浮游生物）、sargasso（马尾藻）、coral（珊瑚）

2. 渔具与捕鱼方式

bait / baits / baited（鱼饵/上饵）、hook / hooks / hooked（鱼钩/钩住）、harpoon（鱼叉）、gaff / gaffed（鱼钩/用鱼钩拉鱼）、lance（长矛）、spear（矛）、cord（绳/钓绳）、wire（金属线/钓线）、coil / coils / coiled（盘绳）、noose（套索）、snares（套索/陷阱）、club / clubbed（木棒/用棒击鱼）、knives / knifing（刀/刀切）、hatchet（小斧）

3. 船只与航海

skiff（小帆船/小艇）、deck（甲板）、hull（船体）、mast / masts（桅杆）、sail / sails / sailing / sailed（帆/航行）、stern（船尾）、tiller（舵柄）、rudder（舵）、gunwale（舷缘）、oar（桨）、thole（桨架）、plank / planking / planks（船板）、rig / rigged（索具/装配）、lashings（绑索）、buoys（浮标）、anchor / anchored（锚/锚定）、harbour / harbours（港口）、docks（码头）、shore / ashore / inshore（岸/靠岸/近岸）、beach / beaches（海滩）、cove（小海湾）、bight（海湾）、gulf（海湾）、tide（潮汐）、surf（浪）

4. 出海动作

rowing / rowed（划船）、steering / steered / steer（掌舵）、haul / hauled（拖、拉）、hoist / hoisted（升起）、lash / lashed（绑紧）、tied / untie / untied（系/解）、coil / coiled（盘绳）、splice（接绳）、sink / sank / sinking（下沉）、submerged（没入水中）、swamped（被浪淹没）、drift / drifted / drifting（漂流）、towed / towing（拖曳）、pulling（拉）、swung（摆动）、lurch（突然倾斜）、taut（绷紧）、tension（拉力/紧张）、strain（拉力/受力）

5. 海况与天气

breeze（微风）、calmer（更平静）、easterly（东风）、freshening（风变强）、hurricane（飓风）、norther（北风）、windless（无风）、phosphorescence / phosphorescent（海面磷光）、cirrus（卷云）、cumulus（积云）、starlight（星光）

6. 鱼体与处理

gill / gills（鳃）、fin / fins（鳍）、dorsal（背鳍的）、pectoral / pectorals（胸鳍的）、belly（鱼腹）、jaw / jaws（颌）、maw（鱼胃/口部）、tail / tails（尾）、spine（脊骨）、backbone（脊骨）、vertebrae（脊椎）、cartilage（软骨）、liver / livers（肝）、fillets（鱼片）、carcass（残骸）、gutted（去内脏）、guts（内脏）、bleeding / bled（放血）、salting（盐腌）、skinning（剥皮）、butchered（宰切）

7. 其他直接相关

fisherman（渔夫）、fished（捕鱼）、fishes（鱼）、motorboats（摩托艇）、smacks（小型渔船）、speedboat（快艇）

最核心的一组可优先记：marlin, shark, tuna, bait, hook, harpoon, gaff, skiff, mast, sail, stern, tiller, rudder, gulf, tide, breeze, hurricane, fisherman, rowing, steering, haul, lash, drift, sink, gills, fins, fillets。
