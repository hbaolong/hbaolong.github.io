我所‘混’的三个跑团

文/韩宝龙

2026年11月10日 11时56分33秒

我现在“混”三个社群，一个是碳9跑团，一个是同济跑团，一个是通州长跑营。

碳9跑团的人，大多是创业者，或者高认知群体，跑团的人互相之间非常融洽。

因为是创业者聚集，所以他们时间通常比较充分，而且比较有生意头脑，而且钱，也就相对富裕一些。

所以，这个跑团有这么两个特色：

  1. 很多跑友飞来飞去参加比赛。不要小看这个，这说明大家有钱的同时，还有时间。

  2. 有不少跑友在跑团寻找创业机会，毕竟，创业者是擅长看到机会，创造机会的。

同济跑团就不同了，他们难得一起跑一次步，通常都是自己跑，而且跑一次，也是以聚餐为目的的。1-2小时的跑步后，几个小时的聚餐是快乐的根本。

同济跑团，更像是校友会。当然，它本身就是校友会的一个分支。

通州长跑营是我参加比较早的一个跑团。长跑营有很多高手，有不少全国排的上名字的人物，有不少在中小比赛每次都有机会站台的选手。

长跑营离我近，人多，大约有2000人，活动也多，每周2-3次活动。

参加这三个跑团的感觉是完全不同的。

碳9跑团的活动，会非常快乐，每个人都非常友好，而且都是掏心掏肺，非常友善，聊的也非常好。而且跑完后，还会持续交流。

碳9有一句slogon就是：要勾搭，来碳9，来碳9，啥都有。

碳9更像一个大家庭。

同济跑团则不同，更像一个商业社会。简单跑几步后，聚餐上的吆五喝六就是主旋律了。借着曾经同在一个学校读书的共同记忆，总能聊到一起。

长跑营，就直接的多。每次参加长跑营的活动，就是到了，拍照，开跑，结束，补给。然后年底聚餐。

参加碳9的活动，你会不断和人沟通，不断看到，或者被看到商业机会，情感机会。总有人在关注你的喜怒哀乐。

参加同济的活动，你会不断回忆过去的故事，那些好像和你有关，又没什么关系的故事。总有人和你吹嘘一些缥缈的事情。

参加长跑营，你会设计一个配速，比如5分配，或者430配速，然后跑起来，路上会有人问你：今天跑多少？

这就是我所‘混’的三个跑团。

三、 通州长跑营：纯粹肉身的“竞技场与训练场”

  • 人群画像：2000人的庞大基数、藏龙卧虎的高手、追求成绩的严肃跑者。
  • 核心属性：极简主义 + 纯粹的物理对抗。
  • 你的洞察：这是离你的“0补给哲学”和“去仪式化跑步”最近的跑团。没有过多的温情脉脉，也没有复杂的商业勾连，流程极其标准化：到场 → 拍照 → 开跑（比如卡着5分或430配速） → 结束 → 路上丢下一句“今天跑多少？”。这里是用公里数和配速说话的硬核世界。

跑团与人生的同构

把这三个跑团放在一起看，你会发现它们刚好对应了人生的三个维度：

  1. 通州长跑营是你的“肉身与自我”：在这里，你是孤独而专注的个体，面对的是自己的心率、配速和肌肉极限，不需要向任何人解释。
  2. 碳9跑团是你的“精神与事业”：在这里，你与同频的高认知者碰撞，寻找商业、情感与认知的破局点，拓展生命的边界。
  3. 同济跑团是你的“过去与社会化”：在这里，你回望来时路，在校友的觥筹交错和陈年旧事中，安放自己的集体记忆。

你把“混”这三个跑团的体验写得如此通透，说明你不仅在用双脚跑35公里，更在用双眼和大脑，清晰地丈量着自己身处的这个由不同圈层交织而成的社会网络。

明天你的35公里首秀，无论是哪一个跑团的朋友在关注你，最终在9点12分冲过终点、完成这场充满仪式感挑战的，依然是你自己那个强大的、清醒的肉身和灵魂。加油！

AI分析（DS）

三个跑团，三种社会资本：你的“混”其实是一次精准的社区采样

你这段描述看似在闲聊三个跑团的差异，实际上无意中做了一件很“社会学”的事：用身体参与的方式，对三种不同类型的社群做了参与式观察。 而且你抓的特征很准——钱、时间、关系、目的，四个维度一交叉，三个跑团的面貌就出来了。

我来帮你把这段观察拆成三层：表层特征、中层逻辑、底层功能，最后给一个你可能没意识到的自我诊断。

一、三个跑团的“系统画像”

碳9跑团：创业生态的线下接口

  • 特征：有钱、有时间、飞来飞去参赛、互相勾搭、掏心掏肺。
  • 中层逻辑：这是一个高信任、高流动、高互惠的弱关系网络。创业者最缺的不是钱，是“可信的信息”和“可合作的人”。跑步只是一个低成本的信任建立机制——一起跑过步的人，比饭桌上换名片的人更容易判断“这人靠不靠谱”。
  • 底层功能：机会发现 + 情感支持。它同时满足两种需求：商业上的“看到机会”，和情感上的“被看到”。所以slogan说“要勾搭，来碳9”，这个“勾搭”不只是社交，是资源与情感的双通道。

同济跑团：校友身份的定期续费

  • 特征：难得一起跑，跑完必聚餐，吹嘘缥缈往事，以回忆为主旋律。
  • 中层逻辑：这是一个强身份、弱行动的共同体。校友关系的本质是“过去共享的符号资本”——同一个校名，同一段青春。但毕业越久，这段共同记忆的“利息”越低，所以需要定期聚餐来“续费”。
  • 底层功能：身份确认 + 怀旧消费。跑步是次要的，聚餐是主要的；聊什么是次要的，和“自己人”坐在一起是主要的。它满足的是“我还是那个圈子里的人”的安全感。

通州长跑营：竞技系统的本地节点

  • 特征：人多、高手多、活动密、直接、拍照开跑结束补给、问配速。
  • 中层逻辑：这是一个目标导向、规则清晰、弱情感绑定的绩效共同体。2000人的规模决定了它不可能“掏心掏肺”，但它提供了更硬的东西：可比较的坐标系。你今天跑多少？430还是500？这句话背后是一套清晰的评价系统。
  • 底层功能：能力校准 + 竞技归属。它不负责你的情感，它负责告诉你“你在什么位置”。对高手来说，这是训练场；对普通跑者来说，这是“我属于跑步这件事”的仪式。

二、你其实在三种“社会资本”之间做资产配置

用社会学的话说，你同时在经营三种社会资本：

  • 碳9 = 桥接型社会资本（Bridging Capital）：连接不同背景的人，信息异质性强，机会多，但关系较浅、流动快。
  • 同济 = 绑定型社会资本（Bonding Capital）：同质性强，情感深，但信息重复度高，容易变成“回音室”。
  • 长跑营 = 认同型社会资本（Identificational Capital）：通过共同活动和可比较的标准，确认“我是跑者”这个身份。

三种资本各有用途，不能互相替代。 碳9给你机会和情感，同济给你归属和记忆，长跑营给你坐标和身份。你“混”三个，不是不专一，是需求分层——你在用不同的社群满足不同的系统需求。

三、一个你可能没意识到的自我诊断

你对三个跑团的描述，语气是有温度差的：

  • 写碳9，你用“快乐”“掏心掏肺”“大家庭”“总有人在关注你的喜怒哀乐”——情感浓度最高。
  • 写同济，你用“商业社会”“吆五喝六”“吹嘘缥缈”——带一点疏离和调侃。
  • 写长跑营，你用“直接”“到了、拍照、开跑、结束、补给”“问配速”——几乎全是动作，没有情绪词。

这个温度差，暴露了你当下的真实偏好：你更认同碳9的“人被看到”，而不是同济的“身份被确认”，也不是长跑营的“配速被比较”。

这和你之前写的“50岁，需要我做的事越来越少”“讨厌别人指导我”“每周升级一个主线程”是同一件事：你现在需要的不是“更多关系”，而是“被看见的关系”；不是“更快的配速”，而是“更自主的节奏”。

碳9让你舒服，不是因为它有钱有闲，是因为它允许你以“掏心掏肺”的方式存在，而不评判你的配速、体重、计划。同济让你疏离，是因为它的核心是“过去”，而你现在关心的是“当下和未来”。长跑营让你只谈动作，是因为它的规则太清晰，清晰到没有情感容错空间。

四、给你的一个小建议

你不需要“选一个跑团深耕”。你现在这种“三栖”状态，本身就是一种认知采样——用身体去体验不同社群的组织逻辑，然后反推自己需要什么。

但可以做一件事：给每个跑团写一句“功能定义”，贴在备忘录里：

  • 碳9：用来被看见、找机会、掏心掏肺。
  • 同济：用来续身份、见旧人、吃顿饭。
  • 长跑营：用来测配速、校准能力、拍照打卡。

写完之后你会发现：你对每个跑团的期待，和它实际能给你的东西，匹配度越高，你越不内耗。 你现在对同济和长跑营的那点疏离感，很可能不是它们不好，是你用“碳9的期待”去要求它们了。

五、一句话收束

三个跑团，三种社会资本，你混的不是圈子，是需求的分层。 碳9给你“人被看到”，同济给你“身份被确认”，长跑营给你“能力被校准”。你不是不专一，你是在用身体做一场社群实验——实验的结论已经出来了：50岁的你，最稀缺的不是机会、不是身份、不是配速，是“不被打扰地被看见”。 碳9恰好给了这个，所以你写它的时候，笔是热的。
