增肌计划

第一周（7/19 ~ 7/25）运动和饮食安排

说明： - 早餐固定（每天）：3个全蛋 + 2个蛋清 + 50g燕麦 + 1根香蕉 - 训练后加餐固定（每天）：1勺蛋白粉 + 1根香蕉 - 晚餐代号： - A餐 = 150g猪里脊 + 200g米饭 + 200g蔬菜 - B餐 = 150g鸡胸 + 200g红薯 + 200g蔬菜 - C餐 = 150g鱼/豆腐 + 200g糙米饭 + 200g蔬菜 - 晨跑要求：配速5’20”-5’40”，心率135-145 bpm。如有疲劳或内踝不适，可缩短至3km或改为快走。

力量训练详细动作

推日（胸/肩/三头）： - 4组标准俯卧撑（10-15次） - 3组下斜俯卧撑（10-12次） - 3组窄距俯卧撑（8-10次） - 3组椅子臂屈伸（力竭） - 3组负重平板支撑（45-60秒）

拉日（背/二头/核心）： - 4组引体向上（力竭，可用弹力带辅助） - 3组澳式引体（10-12次） - 3组弹力带划船（12-15次） - 3组悬垂举腿（8-12次） - 3组侧平板支撑（30-45秒/侧）

腿日（臀/腿/核心）： - 4组靠墙静蹲（45-60秒） - 4组保加利亚分腿蹲（8-12次/侧） - 3组负重臀桥（15-20次） - 3组提踵（20次） - 3组鸟狗式（12次/侧）

执行要点

  • 晨跑心率：控制在135-145 bpm，配速约5’20”-5’40”
  • 力量训练强度：每组最后2-3次应感到吃力，组间休息60-90秒
  • 睡眠：每晚22:30前入睡，保证7-8小时
  • 水分：全天饮水2.5-3升
  • 内踝监测：如跑步或保加利亚分腿蹲时出现疼痛，可暂停该动作，改用靠墙静蹲或游泳替代
  • 晚餐若没有时间准备，可用等量瘦肉和主食替代，保持蛋白质摄入即可。固定饮食是为了减少决策成本，不是必须精确执行。如果某天特别疲劳，可以跳过训练，第二天继续按计划执行，不必补前一天的内容。
