Les Misérables书名解

文/韩宝龙

2026年11月26日 07时15分26秒

先说发音

Les Misérables 的标准法语发音如下：

/le mi.ze.ʁabl/

逐音节分解：

部分 发音 近似英语/汉语

Les /le/ 类似英语 lay，但更短促，舌头不滑向 /i/ 音；类似汉语“勒”但元音开口略大

Mi- /mi/ 类似英语 me，类似汉语“咪”

-sé- /ze/ 浊辅音 /z/ + 类似英语 say 的元音，类似汉语“贼”但声带振动

-rables /ʁabl/ 小舌颤音 /ʁ/（类似漱口声）+ /a/ + /bl/，末尾 /l/ 舌尖抵上齿龈，类似汉语“哈布乐”但“哈”带喉音

重音：法语没有英语式的单词重音，整句语调自然落在最后一个音节 /ʁabl/ 上，稍拖长。

连诵：Les 末尾的 /z/ 音与 Misérables 开头相连，听起来像 /le zi.mi.ze.ʁabl/，这是自然语流中的连诵现象。

常见错误： • 不要读成英语 /ˌmɪzəˈrɑːbəlz/（米泽拉伯斯）

• 不要省略末尾的 /s/，Misérables 是复数，/s/ 虽然不发音，但前面的元音不因此改变

• 不要把小舌音 /ʁ/ 读成大舌音或英语 /r/

一句话速记：勒 咪-贼-哈布乐（“哈”带喉咙里的小舌颤动，末尾“乐”舌尖抵上牙）

再说这个名字的韵味

Les Misérables 是雨果 1862 年小说原名，逐层拆开看非常讲究。

一、语法结构：定冠词 + 形容词名词化

• Les = 法语复数定冠词，相当于英语 the，用于阳性复数名词前。

  • Misérables = 形容词 misérable 的阳性复数形式。 • 法语里 “les + 形容词” 可以整体名词化，指“一类人”，类似英语 the rich / the poor / the young。

    • 所以 Les Misérables 字面不是“悲惨的世界”，而是 “那些悲惨的人们 / 被苦难标记的一群人”。

中文译作《悲惨世界》是苏曼殊先拟“惨世界”、李丹等改定“悲惨世界”的意译——把“一群人”扩成“他们所处的世间”，反而更有汉语重量。

二、词源：misérable ← 拉丁 miser

• 拉丁 miser = 可怜的、不幸的、值得怜悯的（动词 miserari = 哀悼、同情）

• 拉丁 miserabilis = 值得怜悯的 → 古法语 miserable → 现代法语 misérable

  • 英语 miserable 同源，但英语 miser 后来滑向“吝啬鬼”，法语 misérable 没走那条路，始终扣在“苦”上。

三、词义的双刃（雨果选它的关键）

法语 misérable 同时压着两层意思：

  1. 被动的苦：贫苦的、赤贫的、受苦的（芳汀、珂赛特、街垒边的孩子）

  2. 主动的贱：卑劣的、无耻的、混蛋（冉阿让抢小瑞尔威时自骂 Je suis un misérable；马吕斯穷得没法跟珂赛特走时也这么说）

雨果原本考虑过书名 Les Misères（misère = 苦难/贫困，纯被动义），最后改成 Les Misérables，就是把“受害者”和“罪人”焊在一起——

不是只写穷人，而是写“被社会判成低等、又真在低处挣扎”的那一整层人。冉阿让一人就同时占两头：可怜的苦役犯 + 曾想报复社会的恶人，主教照亮他之后才慢慢脱出“misérable”的壳。

四、发音与形态

• 音标：/le mize.ʁabl/（les 连诵，misérables 末音节轻读）

• 单数：le misérable（那个可怜人/那个混账）

• 复数：les misérables

  • 口语简称：Les Mis（音乐剧、电影宣传通用）

五、一句话收束

Les Misérables = “les” 把形容词钉成一类人，“misérable” 又同时含着“苦”与“贱”——雨果用这个书名宣布：他写的不是“世界”，是那些被世界叫做“悲惨虫豸”的人；中文译成“悲惨世界”，是把这群人脚下的土也一起译了出来。
