单词故事：‘ious’，充满….的。

文/韩宝龙

2026年11月7日 18时30分07秒

单词故事

-ious 是一个形容词后缀，来自拉丁语 -iosus / -iosus，和英语的 -ous 是同一家族。

它的核心意思可以概括为：

“充满……的、具有……性质的、倾向于……的”

也就是说，它本身不表示一个具体意思，而是把前面的词根变成形容词，说明“这个东西有某种性质”或“充满了某种东西”。

常见例子

  • vicious = vice / vitium（恶习、败坏）+ -ious → 充满败坏的 → 恶毒的

  • anxious = anx-（收紧、窒息）+ -ious → 被收紧的 → 焦虑的

  • curious = cur-（关心、注意）+ -ious → 充满探问的 → 好奇的

  • suspicious = suspic-（从下看、怀疑）+ -ious → 充满怀疑的 → 可疑的、多疑的

  • delicious = delic-（诱惑、愉悦）+ -ious → 充满愉悦的 → 美味的

  • religious = relig-（束缚、虔敬）+ -ious → 具有宗教性质的 → 宗教的、虔诚的

  • serious = ser-（严肃、沉重）+ -ious → 有严肃性质的 → 严肃的

  • precious = preti-（价值）+ -ous 变体 → 有价值的 → 珍贵的

  • conscious = con-（一起）+ sci-（知道）+ -ous → 有知的 → 有意识的

拼写家族

它其实是 -ous 的一个变体：

后缀 例子 说明
-ous famous, dangerous 最常见
-ious vicious, anxious, curious 词根常以 i 结尾
-eous gorgeous, courteous 词根常以 e 结尾
-uous continuous, ambiguous 词根常以 u 结尾

所以不要把它看成独立的“ious = 某种意思”，而应看成：

词根 + -ious = “充满/具有词根所述性质的”

回到 vicious

vicious 不是“ious 表示恶毒”，而是：

vici-（恶习、败坏）+ -ous → 充满败坏的 → 恶毒的、凶猛的

一句话：-ious = “充满……的 / 具有……性质的”，它只负责把词根变成形容词，具体意思由词根决定。
