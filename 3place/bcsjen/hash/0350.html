From SQUAD 到 ARMY，英语中的军队编制

文/韩宝龙

2026年11月28日 06时10分01秒

军队编制像一套“模块化架构”：底层是班/排/连/营，中层是团/旅，高层是师/军/集团军/方面军。英语常用序列（由小到大）：

Squad → Platoon → Company → Battalion → Brigade → Regiment（位置因国而异） → Division → Corps → Army → Army Group

中文对应大致是： 班 → 排 → 连 → 营 → 旅 → 团 → 师 → 军 → 集团军 → 方面军 （注：团和旅在英美体系里位置不完全固定；解放军现行陆军常见是“军—旅—营—连—排—班”，团已从主战序列淡出。）

各词来历（词源+历史底色）

Squad（班） 意大利语 squadra“方阵、小队”← 通俗拉丁 quadra“四方形、四人组”（与 square 同源）。原意就是“摆成小方块的一撮人”，最基层作战单元。

Platoon（排） 法语 peloton“小球、小队”← pelote“球、团”（pellet 小皮球）。17 世纪步兵把若干小队卷成一个“小球”机动，英语借来变 platoon，字面像“一小团人”。

Company（连） 拉丁 compania“一起吃面包的人”← com-（共同）+ panis（面包）。中世纪军事/商业行会里“同锅吃饭的一伙人”，后固定为连级单位——词根就是“一起分面包”。

Battalion（营） 意大利语 battaglione“小战斗队”← battaglia“战斗”← 通俗拉丁 battalia ← 拉丁 battere“击打”。1580 年代入英语，原指“一小支战斗队”，1708 年起定为“团的一部分”。

Brigade（旅） 法语 brigade ← 意大利语 brigata ← brigare“争斗、骚扰”/briga“麻烦、争斗”。17 世纪古斯塔夫·阿道夫把步骑炮混编成临时战斗群，法国蒂雷纳 1667 年设“旅”由准将指挥。团是“你是谁”（身份/荣誉），旅是“这次你干什么”（任务编组）——所以旅天然带临时、任务导向色彩。

Regiment（团） 拉丁 regimentum“统治、管理”← regere“治理、指挥”（同 regal / reign / rector）。16 世纪末入军事用语，指“受统一指挥的一支部队”；后来演变为行政与荣誉共同体（团长自募、自装、同团终身），所以团比旅更“像家”。

Division（师） 拉丁 divisio“分割”← dividere“分开”。原意“从全军里切出来的一大块”，能独立作战的大单位。法语 division 直接借入英语。

Corps（军） 法语 corps“身体”← 拉丁 corpus“躯体”（同 corporal / incorporate）。字面“军队的一个躯干”，比师高一级，通常辖若干师+直属队。

Army（集团军/陆军） 古法语 armée ← 拉丁 armata“武装的（队伍）”← arma“武器”。原指“武装起来的一整支”，后来既可指国家陆军，也可指战区级“集团军”。

Army Group（方面军/集团军群） 英语复合词，二战德军 Heeresgruppe 直译风行，指多个 Army 合成的最高野战编组。

小提醒：读《悲惨世界》滑铁卢章时，威灵顿麾下是 brigade（旅）→ division（师） 的英式体系；奥兰治亲王指挥的是尼德兰旅/师；拿破仑那边是 corps（军）→ division → brigade。雨果写“brigade”时，指的就是那批 3000–5000 人、由准将带、夹在营和师之间的任务编组。
