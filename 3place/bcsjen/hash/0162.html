单词故事：errand

单词故事

关于 errand，信息整理如下：

🗣️ 发音

  • 英式：/ˈerənd/ (ER-uhnd)

  • 美式：/ˈerənd/ (ER-uhnd)

  • 复数：errands

📜 词根与词源

errand 的核心是 “被派出去传的话、办的差事”。

  • 古英语 ærende：意为“消息、使命、差事”。

  • 原始日耳曼语 *airundiją：同源词包括古诺斯语 eyrindi（消息、差事）、古高地德语 ārunti（消息、命令）。

  • 最初偏“传信、传话”，后来扩展为“被派出去办的具体事情”。

  • 同族词：errand 本身派生不多；errand boy（跑腿男孩）是常见复合词。

  • 注意：errand（差事）和 errant（漫游的；错误的）拼写相近，但词源和意思不同。

📖 核心含义

  1. 差事、跑腿的事：被派出去办的短程任务。

  2. 使命、任务（较正式/文学）：an errand of mercy（慈善使命）。

  3. 跑腿：run errands。

它通常指短程、具体、受指派的事，不是宏大使命。

📖 历史上的著名用法

  • 日常与家庭语境：run errands（跑腿）是长期固定搭配，指买菜、送信、取东西等日常杂事。

  • 宗教/文学语境：errand of mercy（慈悲的使命）常见于19世纪文学，指去帮助、探望、救援某人。

  • 莎士比亚与近代英语：errand 常指“被派去传的话/办的事”，带“受差遣”的意味。

  • 19世纪小说：常写仆人、孩子、穷人被 sent on errands，体现底层人物的被支配状态。

🌐 当代著名用法

  • run errands：跑腿、办杂事

    • I have to run some errands this afternoon.（我下午要去办点事。）

  • errand boy：跑腿的人；也可贬义指“听人差遣的人”

  • send sb on an errand：派某人去办事

  • on an errand：在办事途中

  • fool’s errand：徒劳的差事、白费劲的任务

  • errand of mercy：慈悲使命（较正式）

🔁 与近义词区别

词 含义 侧重点
errand 差事、跑腿 短程、具体、受指派
task 任务 最通用，可大可小
mission 使命 更宏大、更正式
chore 杂务 日常家务，不一定被派
assignment 任务 工作/学习中被分配的任务

errand 比 task 更具体、更日常，比 mission 小得多。

📈 当下流行度

高频词。 run errands 是日常口语极常见搭配；errand boy、fool’s errand 也很活跃。

📚 在《悲惨世界》中的可能语境

在英文版中，errand 可能用于：

  • 珂赛特：在德纳第家被 sent on errands，天不亮就去打水、跑腿。

  • 芳汀：为珂赛特的事奔走，像一场痛苦的 errand。

  • 冉阿让：为他人办事、送钱、救人，可带 errand of mercy 的色彩。

  • 底层人物：被差遣、被支配，errand 常标记他们的无权状态。

  • 德纳第：派孩子跑腿、派妻子办事，自己不动。

✍️ 注释建议

errand：n. 差事，跑腿的事；使命。

词源：古英语 ærende（消息、使命）→ 原始日耳曼 *airundiją。

搭配：run errands（跑腿）；errand boy；fool’s errand（徒劳的差事）；errand of mercy（慈悲使命）。

注意：errand（差事）≠ errant（漫游的；错误的）。

💎 一句话

errand 是“被派出去办的一件小事”——跑腿、送信、取东西。它不大，但常标记一个人被差遣、被支配的位置。在《悲惨世界》里，珂赛特天不亮被派出去打水，那就是最沉重的 errand。
