单词故事：elusive

文/韩宝龙

2026年11月9日 08时06分27秒

单词故事

关于 elusive，信息整理如下：

🗣️ 发音

  • 英式：/iˈluːsɪv/ (ee-LOO-siv)

  • 美式：/iˈluːsɪv/ (ee-LOO-siv)

  • 重音在第二音节。

  • 动词：elude（逃避；使难以理解/找到）；名词：elusiveness（难以捉摸）

📜 字父与词源

字父（前缀）：e- / ex- = 出、向外、离开。

词根：lud- / lus- = 玩、戏弄、欺骗（拉丁语 ludere，过去分词 lusus）。

后缀：-ive = 具有……性质的。

整体：“玩着躲出去、从手中滑走” → 难以抓住的、难以捉摸的。

  • 拉丁语 eludere：由 e-（出）+ ludere（玩/戏弄）构成，字面意为 “玩着逃出去、躲开”。

  • elusus → elusive。

  • 进入英语约 18世纪。

  • 同族词：elude、elusion（逃避）、elusiveness；ludicrous（荒唐的，同源于“玩/戏”）、illusion（幻觉，il- 向内 + ludere）、delusion（欺骗）。

注意：elusive 不是来自 clus-（关闭），不要和 exclusive 混。exclusive 是“关在外面”，elusive 是“玩着逃出去”。

📖 核心含义

  1. 难以找到的、难以捉摸的：不容易被发现、抓住或描述。

    • an elusive criminal（难以抓获的罪犯）

    • an elusive answer（难以捉摸的答案）

  2. 难以实现的、难以达到的：目标、梦想、成功等。

    • an elusive goal（难以实现的目标）

  3. 难以记住/描述的：概念、感觉、品质。

    • an elusive quality（难以言说的品质）

  4. （动物）难以捕获的：elusive prey（难以捕获的猎物）。

它比 difficult 更具体，偏 “抓不住、说不清、找不到”；比 vague 更强调逃避捕捉；比 slippery 更正式、更抽象。

📖 历史上的著名用法

  • 18—19世纪文学与哲学：elusive 常写 真理、幸福、意义、美 的难以捉摸。它带一种“越追越远”的哲学感。

  • 19世纪小说：常写难以抓获的罪犯、难以理解的人物、难以得到的爱情。在《悲惨世界》英译本中，冉阿让的身份、沙威追捕的对象、芳汀想要的安稳，都可被写成 elusive。

  • 科学写作：elusive particle（难以探测的粒子）、elusive cure（难以找到的疗法）。

🌐 当代著名用法

  • elusive goal / dream：难以实现的目标/梦想

  • elusive answer / concept：难以捉摸的答案/概念

  • elusive quality：难以言说的品质

  • elusive prey / criminal：难以捕获的猎物/罪犯

  • remain elusive：仍然难以找到/实现

    • The cause of the disease remains elusive.

  • prove elusive：证明难以捉摸

    • Success proved elusive.

  • elusive memory：模糊难追的记忆

  • elusiveness：难以捉摸

🔁 与近义词区别

词 含义 侧重点
elusive 难以捉摸/找到/实现 偏抓不住、躲开、说不清
illusive 虚幻的、迷惑人的 来自 illusion，偏假的、幻觉的
exclusive 排他的、独家的 来自“关在外面”
vague 模糊的 偏信息不清，不一定“逃”
slippery 滑的；难以对付的 偏物理/比喻“抓不住”
evasive 回避的、推脱的 偏人故意躲闪

关键辨析：

  • elusive = 难以抓住/找到/描述（东西本身难抓，或人躲得快）。

  • illusive = 虚幻的、骗人的（来自 illusion）。

  • evasive = 故意回避的（多指人/回答）。

📈 当下流行度

中高频，偏书面/新闻/学术。 elusive goal、remain elusive、elusive answer 都很常见；日常口语更常说 hard to find 或 hard to pin down。属于“认识且能准确使用”的词。

📚 在《悲惨世界》中的可能语境

  • 冉阿让：对沙威来说，他是一个 elusive 的追捕对象——多次消失、改名、逃脱。

  • 沙威：他追的不仅是人，也是一个 elusive 的“正义”定义。

  • 芳汀：她想要的安稳生活、女儿的未来，都是 elusive。

  • 幸福/正义/真相：雨果常写这些东西“难以捉摸”，不是不存在，而是总从手中滑走。

  • 米里哀主教：他的善不 elusive；它具体、可触、开门。

✍️ 注释建议

elusive：adj. 难以捉摸的；难以找到/抓住/实现的；难以描述的。

字父：e-/ex- = 出；词根 lud-/lus- = 玩、戏弄（拉丁 ludere）；后缀 -ive。字面“玩着逃出去”。

同族：elude, elusion, elusiveness；illusion, delusion, ludicrous。

注意：elusive（难抓）≠ illusive（虚幻）≠ exclusive（排他/独家）。

搭配：elusive goal/answer/quality/prey；remain elusive；prove elusive。

在《悲惨世界》中，冉阿让对沙威是 elusive；幸福对芳汀是 elusive。

💎 一句话

elusive 是“玩着逃出去”——你伸手，它滑走；你追，它消失；你想说清，它说不清。它从拉丁语“戏弄着躲开”出发，核心不是“不存在”，而是抓不住。在《悲惨世界》里，冉阿让对沙威是 elusive，幸福对芳汀也是 elusive。
