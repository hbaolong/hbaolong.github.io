单词故事：vicious

文/韩宝龙

2026年11月7日 18时26分57秒

单词故事

关于 vicious，信息整理如下：

🗣️ 发音

  • 英式：/ˈvɪʃəs/ (VISH-uhs)

  • 美式：/ˈvɪʃəs/ (VISH-uhs)

  • 重音在第一音节。

  • 名词：viciousness（恶毒；凶猛）；副词：viciously（恶毒地；猛烈地）

📜 字父与词源

字父（前缀）：无。

词根：viti- / vici- = 恶习、缺陷、败坏（拉丁语 vitium）。

后缀：-ous = 充满……的、具有……性质的。

整体：充满恶习/败坏的 → 恶毒的、凶猛的、恶性的。

  • 拉丁语 vitiosus：来自 vitium（缺点、恶习、败坏），意为“有缺陷的、败坏的、恶毒的”。

  • 经古法语 vicieus 进入英语，约 14世纪。

  • 同族词：

    • vice：恶习；罪恶（同源于 vitium）

    • vitiate：损害；使失效（同源）

    • vicious 本身与 vice 关系最近：vice + -ious 的变体。

  • 注意：vicious 不是来自 vicious circle 的“circle”，它核心是“恶习/败坏”。

所以它的底层不是“凶”，而是 “坏到骨子里、充满恶习”。

📖 核心含义

  1. 恶毒的、凶残的：人或行为充满恶意，故意伤害。

    • a vicious attack；a vicious dog

  2. 恶性的、严重的：疾病、循环、问题等自我加剧、难以控制。

    • a vicious circle（恶性循环）；a vicious disease

  3. 猛烈的、激烈的：攻击、批评、风暴等。

    • a vicious storm；vicious criticism

  4. （古）有缺陷的、败坏的。

它比 cruel 更偏主动恶意+凶猛；比 violent 多一层“恶毒/故意伤害”；比 brutal 少一点“身体残暴”，多一点“阴狠”。vicious circle 是固定搭配，指“恶性循环”。

📖 历史上的著名用法

  • 莎士比亚与近代文学：vicious 常写恶人、恶犬、恶行，也写“败坏的品性”。莎士比亚笔下 vicious 可指道德败坏，也可指凶猛。

  • 19世纪文学：常写暴力、犯罪、酗酒、贫困中的恶性循环。vicious circle 在19世纪社会学/医学写作中逐渐固定。

  • 《悲惨世界》英译本可能语境：

    • 德纳第的 vicious 算计与虐待；

    • 苦役场/街垒中的 vicious 暴力；

    • 芳汀陷入的 vicious circle：贫困→卖身→更贫困；

    • 沙威的 vicious 追捕？更准确是 relentless，不是 vicious。

🌐 当代著名用法

  • vicious attack：恶毒攻击；凶残袭击

  • vicious dog：恶犬

  • vicious circle：恶性循环（极常用）

  • vicious cycle：恶性循环（同义）

  • vicious criticism / rumors：恶毒批评/谣言

  • vicious disease：恶性疾病

  • viciously：恶毒地；猛烈地

    • He was viciously attacked in the press.

  • viciousness：恶毒；凶猛

🔁 与近义词区别

词 含义 侧重点
vicious 恶毒的；凶猛的；恶性的 偏主动恶意 + 凶猛 + 恶性循环
cruel 残酷的 偏造成痛苦，不一定“凶猛”
violent 暴力的 偏身体力量/暴力行为
brutal 残忍的 偏身体残暴、无情
savage 野蛮的；凶猛的 偏原始、猛烈
malicious 恶意的 偏故意使坏，不一定凶猛

关键：vicious 不只是“坏”，而是“坏得有攻击性、会咬人、会自我加剧”。

📈 当下流行度

高频词。 vicious circle/cycle、vicious attack、vicious dog 都很常见；新闻、法律、医学、日常都活跃。属于必须主动掌握的词。

📚 在《悲惨世界》中的可能语境

  • 德纳第夫妇：对珂赛特的 vicious 虐待；对芳汀的 vicious 勒索。

  • 芳汀的处境：贫困、债务、羞辱构成一个 vicious circle。

  • 街垒与暴力：vicious 的冲突、追捕、打斗。

  • 沙威：更准确是 relentless / stern，不是 vicious；他不是恶毒，而是冷硬。

  • 米里哀主教：他是 vicious 的反面——不攻击、不报复、不使坏。

✍️ 注释建议

vicious：adj. 恶毒的；凶猛的；恶性的（vicious circle）；猛烈的。

字父：无；词根 viti- / vici- = 恶习、缺陷（拉丁 vitium）；后缀 -ous。

同族：vice, vitiate。

搭配：vicious attack/dog/circle/cycle/criticism；viciously；viciousness。

与 cruel/brutal 区别：vicious 更偏“主动恶意+凶猛+自我加剧”。

在《悲惨世界》中，德纳第是 vicious 的；芳汀陷入 vicious circle；米里哀是反面。

💎 一句话

vicious 从“充满恶习/败坏”出发，核心是“坏得有攻击性”——恶犬咬人、恶毒攻击、恶性循环。它比 cruel 更凶猛，比 violent 更阴狠。当你读到它时，先看语境：是人的恶毒，是动物的凶猛，还是问题的恶性循环。
