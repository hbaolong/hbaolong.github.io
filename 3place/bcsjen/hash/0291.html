单词故事：英语中的最小对立对

文/韩宝龙

2026年11月15日 16时28分37秒

单词故事

一、一个字母，两个世界

plank 和 blank。grass 和 brass。pin 和 bin。

它们只差一个音，意思却隔着很远。你把 /p/ 换成 /b/，木板就变成了空白；你把 /ɡ/ 换成 /b/，草就变成了黄铜。

这种“只差一个音、意义不同”的词对，在语言学里有一个名字：minimal pair，中文通常译作 “最小对立对”。

它是语音学里最基础、也最有用的一对概念。它不只告诉你“这两个词发音像”，它告诉你：这两个音，在英语里是“对立”的，换一个，词就变了。

二、什么才算最小对立对

严格说，一个最小对立对要满足三个条件：

  1. 两个词意义不同：pin 和 bin 是两个东西。

  2. 发音只差一个音：/pɪn/ vs /bɪn/，只差首辅音。

  3. 这个差异出现在同一个位置：都在词首，或都在词中，或都在词尾。

三个条件缺一不可。

  • pin / bin：只差 /p/ vs /b/，词首，意义不同 → 是最小对立对。

  • cat / bat：只差 /k/ vs /b/，词首 → 是最小对立对。

  • ship / sheep：只差 /ɪ/ vs /iː/，词中，意义不同 → 是最小对立对。

  • cat / dog：差太多音 → 不是。

  • cat / cats：只差一个音，但意义是“单数/复数”的语法差异，通常不算典型最小对立对，更偏形态对立。

所以最小对立对的核心不是“拼写像”，是 “音位对立”。

三、它为什么重要

最小对立对是语音学的“实验工具”。它用来证明一件事：某个音在某种语言里是不是独立的音位。

英语里 /p/ 和 /b/ 是对立的，因为 pin / bin、pat / bat、pack / back 都是不同的词。你换掉 /p/，词就变了。所以 /p/ 和 /b/ 在英语里是两个独立的音位。

中文里 /p/ 和 /pʰ/（送气与不送气）是对立的：“爸”和“怕”只差送气，意义不同。但在英语里，/p/ 送不送气不区分意义——pin 的 /p/ 送气，spin 的 /p/ 不送气，但它们是同一个音位。所以英语母语者学中文时，常分不清“爸”和“怕”，因为英语里没有这个对立。

最小对立对，就是用来发现“哪种差异在某种语言里是有意义的”。

四、英语里常见的最小对立对类型

1. 清浊对立：/p/ vs /b/，/t/ vs /d/，/k/ vs /ɡ/

  • pin / bin

  • pat / bat

  • pack / back

  • tie / die

  • town / down

  • coat / goat

  • cap / gap

这是英语里最典型的一类。清辅音和浊辅音在词首对立，意义完全不同。

2. 元音长短/松紧：/ɪ/ vs /iː/，/ʊ/ vs /uː/

  • ship / sheep

  • bit / beat

  • fit / feet

  • full / fool

  • pull / pool

这类对非母语者特别难，因为中文里没有“长短元音对立”这条线。

3. 鼻音对立：/m/ vs /n/ vs /ŋ/

  • sum / sun / sung

  • ram / ran / rang

  • dim / din / ding

词尾鼻音的对立，英语里很稳定。

4. 流音与滑音：/l/ vs /r/，/w/ vs /v/

  • light / right

  • lead / read（读过去式）

  • west / vest

  • wine / vine

/l/ vs /r/ 对很多亚洲学习者是大难点；/w/ vs /v/ 对印欧语外学习者也是。

5. 摩擦音对立：/s/ vs /ʃ/，/f/ vs /v/

  • sip / ship

  • sock / shock

  • fan / van

  • ferry / very

6. 塞擦音对立：/tʃ/ vs /dʒ/

  • cheap / jeep

  • chin / gin

  • chunk / junk

五、你举的 plank / blank 和 grass / brass

plank / blank 是 /p/ vs /b/ 的清浊对立，属于第 1 类。grass / brass 是 /ɡ/ vs /b/ 的首辅音对立，严格说不是同一发音部位的清浊对，但仍然构成最小对立对——因为只差一个音，意义不同。

所以它们都是最小对立对，只是对立的“音”不同。

六、最小对立对不只是“发音练习”

很多人以为最小对立对只是语音课上的辨音练习。其实它有三层用途：

第一，语音教学。 帮学习者分辨母语里没有的对立，比如中文母语者分 /l/ 和 /r/、/ʃ/ 和 /s/、长短元音。

第二，音系分析。 语言学家用它来确定一种语言的音位清单。两个音如果能在相同位置替换并产生不同词，它们就是对立音位。

第三，心理语言学。 研究者用最小对立对测试听者的大脑如何区分语音、如何预测词义。pin 和 bin 在脑电上会引发不同的反应，因为它们触发了不同的词汇通路。

七、最小对立组：不止两个

最小对立对通常是两个词。但如果一组词只差一个音，叫 minimal set（最小对立组）：

  • pin / bin / tin / din / kin

  • pat / bat / cat / rat / hat

  • ship / sheep / shop / shape

最小对立组比最小对立对更能说明一个音位在系统里的位置。

八、和“拼写邻词”的区别

你之前问的“p 和 b 开头、后面相同”的词，如果强调拼写只差一个字母，叫 orthographic neighbors（拼写邻词）。plank / blank 既是拼写邻词，也是最小对立对。但两者不是同一个概念：

  • plank / blank：拼写差一个字母，发音差一个音 → 两者都是。

  • cat / kat（如果 kat 不是词）：只是拼写邻词，不构成最小对立对，因为 kat 不是英语词。

  • ship / sheep：发音是最小对立对，拼写差两个字母 → 是最小对立对，但不是拼写邻词。

最小对立对看的是“音”，不是“字母”。

九、一句话

最小对立对，就是“只差一个音，意义就不同”的两个词。 它是语音学的显微镜：用它，你能看见一种语言里哪些音是“真正有意义的差异”，哪些只是“口音”。pin / bin 告诉你 /p/ 和 /b/ 在英语里是对立的；ship / sheep 告诉你长短元音是对立的；light / right 告诉你 /l/ 和 /r/ 是对立的。

一个音，两个世界。 最小对立对就是那个“一个音”的边界线。
