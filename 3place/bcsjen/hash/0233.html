单词故事：threshold

文/韩宝龙

2026年11月9日 07时51分48秒

单词故事

关于 threshold，信息整理如下：

🗣️ 发音

  • 英式：/ˈθreʃhəʊld/ (THRESH-hohld)

  • 美式：/ˈθreʃhoʊld/ (THRESH-hohld)

  • 注意开头是 /θ/（咬舌音），中间是 /ʃ/（sh 音）；口语中 /h/ 有时很弱。

  • 常见误拼：threshhold（多一个 h），正确是 threshold。

📜 字父与词源

字父（前缀）：无。

threshold 是日耳曼语源单纯词，不是“前缀 + 词根”结构。

词根：threshold- 整体 = 门槛；入口；临界点。

  • 古英语 þrescold / þerscold：意为“门槛”，也指“入口处”。

  • 词源不完全确定。传统上常把它和 thresh（打谷）联系起来，但这一说法并非定论；也有学者认为第一部分与“踩、踏”有关，整体是“被踩踏的横木”。

  • 核心意象一直很具体：门下面那根横木——你进出必须跨过它。

  • 词义从“物理门槛”扩展到：

    1. 入口、起点

    2. 临界点、阈值

    3. 心理/生理承受界限

  • 同族词不多：thresholds（复数）；专业复合词如 threshold level、pain threshold。

所以它的底层不是“门”，而是 “你必须跨过去的那道横木”。

📖 核心含义

  1. 门槛；门口（本义，较具体）

    • stand on the threshold（站在门口）

  2. 开端、起点；临界点

    • on the threshold of a new era（处于新时代的开端）

  3. 阈值、界限；临界值（科技/医学/心理）

    • pain threshold（痛阈）

    • threshold dose（阈剂量）

  4. （政治/选举）得票门槛

    • election threshold（选举门槛）

  5. （心理学）阈限

    • absolute threshold（绝对阈限）

它比 limit 更偏“跨过与否”的分界点；比 entrance 更具体、更带“门槛”意象；比 boundary 更偏临界值/触发点。

📖 历史上的著名用法

  • 《圣经》与文学中的“门口”：threshold 常写站在门口、跨入某地，带“进入新状态”的象征。

  • 19世纪文学：常写人物 on the threshold——站在门口、站在人生转折点。在《悲惨世界》英译本中，可能用于门槛、入口、临界时刻。

  • 心理学与科学：19—20世纪，threshold 成为心理物理学、生理学、工程学核心术语：痛阈、听阈、触发阈值、光电阈值。

  • 政治话语：election threshold（选举门槛）是现代议会制度中的固定词。

🌐 当代著名用法

  • pain threshold：痛阈；忍耐极限

  • threshold level / value：阈值/临界值

  • on the threshold of：处于……的开端/临界点

  • cross the threshold：跨过门槛；进入

  • election / electoral threshold：选举门槛

  • threshold dose：阈剂量

  • absolute threshold：绝对阈限（心理）

  • photoelectric threshold：光电阈值

  • threshold effect：阈值效应

  • at the threshold：在门口；在起点

🔁 与近义词区别

词 含义 侧重点
threshold 门槛；阈值；临界点 偏跨过与否的分界点
entrance 入口 偏进入的地方
limit 限制；极限 最通用，偏“不能超过”
boundary 边界 偏范围界线
brink 边缘 偏濒临某状态，常带危险
cutoff 截止点 偏人为设定的分界

关键：threshold 是“你必须跨过去的那道横木”，所以它天然带有“临界、触发、起点”的意味。

📈 当下流行度

高频词。 科技、医学、心理、政治、日常都常用；pain threshold、threshold value、on the threshold of、election threshold 都是稳定搭配。属于必须主动掌握的词。

📚 在《悲惨世界》中的可能语境

  • 物理门槛：人物站在门口、跨过门槛。

  • 人生临界点：冉阿让站在自首/逃亡的 threshold；芳汀站在坠落边缘。

  • 社会门槛：底层人被挡在“体面社会”的 threshold 之外。

  • 心理阈值：人物承受苦难的 threshold 被推到极限。

  • 革命临界点：街垒前，巴黎处于爆发的 threshold。

✍️ 注释建议

threshold：n. 门槛；入口；开端；临界点；阈值。

字父：无；词源：古英语 þrescold（门槛），词源不完全确定，常与 thresh/“踩踏”联系但非定论。

搭配：on the threshold of；cross the threshold；pain threshold；threshold value；election threshold；absolute threshold。

与 limit 区别：threshold 更偏“跨过与否的分界点/触发点”；limit 更偏“不能超过的界限”。

注意拼写：threshold，不是 threshhold。

💎 一句话

threshold 是“门下面那根横木”——你跨过去，就进入另一个空间；你跨不过去，就被挡在外面。它从具体的门槛，长成了“临界点、阈值、开端”。在《悲惨世界》里，人物常站在 threshold 上：跨过去，命运就变了。
