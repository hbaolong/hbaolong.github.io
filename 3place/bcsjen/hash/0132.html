单词故事

以 -able / -ible 结尾的词，核心意思通常是：

“可……的”“能……的”“值得……的”“具有……性质的”

它们大多来自拉丁语，经法语进入英语。-able 是活后缀，能产，可以造新词；-ible 基本是死后缀，多固定在借词里。

一、最常见的两类

1. 动词 + -able：可被……的 / 能……的

词 构成 含义
readable read + able 可读的
washable wash + able 可洗的
drinkable drink + able 可饮用的
eatable eat + able 可吃的
believable believe + able 可信的
forgettable forget + able 容易被忘记的
manageable manage + able 可管理的
acceptable accept + able 可接受的
adaptable adapt + able 可适应的
comparable compare + able 可比较的
considerable consider + able 相当大的；值得考虑的
desirable desire + able 值得拥有的；令人向往的
preferable prefer + able 更可取的
reliable rely + able 可靠的
suitable suit + able 合适的
changeable change + able 易变的
breakable break + able 易碎的
recyclable recycle + able 可回收的
wearable wear + able 可穿戴的
hackable hack + able 可被黑客入侵的
googleable google + able 可谷歌搜到的

这一类最能产。今天还可以造 doable, fixable, testable, scalable, sustainable 等。

2. 名词 + -able：具有……性质的 / 适合……的

词 构成 含义
comfortable comfort + able 舒适的
fashionable fashion + able 时髦的
knowledgeable knowledge + able 知识渊博的
peaceable peace + able 和平的；不爱争吵的
sizeable size + able 相当大的
saleable sale + able 可销售的
serviceable service + able 可用的；耐用的
marriageable marriage + able 适合结婚的
objectionable objection + able 令人反感的
impressionable impression + able 易受影响的

注意：不是所有 -able 都等于“可被……”。comfortable 不是“可被安慰的”，而是“使人舒适的”；fashionable 是“符合时尚的”。

二、-ible：多固定、少能产

-ible 也表“可……的”，但基本不能随意造新词，多是拉丁借词固化形式。

词 含义
visible 可见的
invisible 不可见的
possible 可能的
impossible 不可能的
terrible 可怕的
horrible 可怕的
sensible 明智的；可感知的
responsible 负责的
accessible 可接近的；可进入的
flexible 灵活的
credible 可信的
incredible 难以置信的
edible 可食用的
eligible 有资格的
feasible 可行的
plausible 似乎合理的
tangible 有形的
intangible 无形的
soluble 可溶的
voluble 健谈的；流利的

规律：-ible 大多来自拉丁语 -ibilis，不能产；不要随便把动词加 -ible 造词。 说 readible 是错的，应为 readable。

三、拼写规律

1. 一般直接加 -able

  • read → readable
  • wash → washable
  • accept → acceptable
  • adapt → adaptable

2. 以 e 结尾：有时去 e，有时保留

去 e： - desire → desirable - value → valuable - note → notable - believe → believable - imagine → imaginable - advise → advisable

保留 e： - manage → manageable - change → changeable - notice → noticeable - service → serviceable - trace → traceable

大致规律：如果去 e 会让 c/g 变硬音，就保留 e。
manage 去 e 成 managable，g 可能读硬音，所以保留 e：manageable。

3. 双写辅音

  • forget → forgettable
  • regret → regrettable
  • control → controllable
  • prefer → preferable（不双写 r，英式常见）
  • refer → referable / referrable（有变体）

4. y 变 i

  • rely → reliable
  • envy → enviable
  • pity → pitiable
  • vary → variable

四、否定前缀规律

  • un- + -able 最常见：
    • unreadable, unwashable, unbelievable, unforgettable, unbreakable, unsuitable
  • in- / im- / ir- / il- + -ible 常见：
    • invisible, impossible, irresistible, illegal, inaccessible
  • 也有 in- + -able：
    • inadvisable, inalienable, insufferable
  • dis- + -able：
    • disagreeable, dishonorable

阅读时看到 un- / in- / im- / ir- / il-，先想“不……的”。

五、语义规律：不止“可被……”

-able / -ible 常见有四层：

  1. 可被……的（被动）
    readable, washable, visible, edible

  2. 能……的 / 会……的（主动倾向）
    changeable（易变的）, impressionable（易受影响的）, perishable（易腐烂的）

  3. 值得……的
    admirable（值得钦佩的）, desirable（值得拥有的）, lovable（可爱的）

  4. 具有……性质的 / 适合……的
    comfortable, fashionable, knowledgeable, peaceable

所以不能机械译成“可被”。formidable 就是典型：它不是“可被恐惧的”，而是固化成了“令人敬畏的、强大的、难对付的”。

六、-able 和 -ible 的核心区别

-able -ible
能产性 高，可造新词 低，多固定
来源 法语/拉丁 -abilis 拉丁 -ibilis
例子 readable, doable, wearable visible, possible, terrible
否定 un- 常见 in-/im-/ir-/il- 常见
拼写 多可直接加 多整体记忆

一句话：-able 是活的，-ible 是死的。 遇到新词，-able 多半能拆；-ible 多半要整体记。

七、和《悲惨世界》阅读相关

你读的英文版里，-able / -ible 高频出现，常带道德或社会判断：

  • miserable：悲惨的（不是“可 miser 的”，是固定词）
  • admirable：值得钦佩的
  • despicable：可鄙的
  • formidable：令人敬畏的；难对付的
  • inevitable：不可避免的
  • insufferable：难以忍受的
  • impoverished 不是 -able，但相关
  • responsible：有责任的
  • sensible：明智的
  • visible / invisible：可见/不可见
  • terrible：可怕的

阅读时可以先判断：

  1. 是不是 动词 + able？→ “可被……的/能……的”
  2. 是不是 名词 + able？→ “具有……性质的/适合……的”
  3. 是不是 -ible 固定词？→ 整体记，不要硬拆
  4. 有没有否定前缀？→ 先加“不”

一句话总结

-able 是英语里最活跃的“可……的”后缀，能产、可造新词；-ible 是它的拉丁化兄弟，多固定、不能随意造。 看到 -able，先想“可被/能/值得”；看到 -ible，先想“这是个固定形容词”。而 formidable 提醒你：有些 -able 已经固化，不能按字面直译。
