单词故事：字父，英文中的那些“姓”

文/韩宝龙

2026年11月2日 11时34分48秒

单词故事

一个英文单词，往往不是一出生就完整的。它像一个人，先有一个“姓”，再有一个“名”。这个“姓”，就是前缀。

前缀是“字父”，是主导字。前缀不决定这个词具体是什么，但它决定这个词“姓什么”、归哪一家、站在哪个框架里。 pre- 姓“前”，post- 姓“后”，sub- 姓“下”，super- 姓“上”，anti- 姓“反”，co- 姓“一起”。后面的词根，才是这个家的孩子，具体叫什么，由它自己填。

所以，读一个长单词，先别急着背。先看它姓什么。

一、否定家族：姓“不”的

这是英语里最大的一族。un-、in-（及变体 im-、il-、ir-）、non-、a-、anti-、contra-、counter-、dis-、de-。

它们不干别的，只负责把意思翻过来。

  • un-：unhappy, unfair, undo
  • in- / im- / il- / ir-：incorrect, impossible, illegal, irregular
  • non-：nonsense, nonstop
  • a-：amoral, atypical
  • anti-：antiwar, antibody
  • contra- / counter-：contradict, counterattack
  • dis- / de-：disconnect, defrost

这一族“姓不”，但“不”的方式不同。un- 是日常的“不”，in- 偏正式，non- 是“非”，anti- 是“反”，de- 是“去掉”。同一个“不”，各有各的门风。

二、方向家族：姓“前、后、上、下、里、外”的

这一族管位置，像给词安了一个坐标。

  • pre- / fore- / pro-：preview, foresee, progress
  • post-：postwar, postpone
  • re-：return, rebuild
  • sub-：submarine, subway
  • super-：supernatural, supermarket
  • in- / im-：inside, import
  • e- / ex-：exit, export
  • inter-：international, internet
  • trans-：transport, transform
  • circum- / peri-：circumstance, perimeter
  • para-：parallel, paramedic

sub- 姓“下”，所以 submarine 在海面之下；super- 姓“上”，所以 supernatural 在自然之上；inter- 姓“之间”，所以 international 在国家之间。方向姓对了，词义的大方向就不会跑偏。

三、数量家族：姓“一、二、三、多、半”的

这一族直接报数。

  • mono- / uni-：monologue, uniform
  • bi- / di-：bicycle, dilemma
  • tri-：triangle, tricycle
  • quadr-：quadrant
  • multi- / poly-：multimedia, polygon
  • semi- / hemi- / demi-：semicircle, hemisphere, demigod

你之前提到的 twi-，其实是古英语里“二”的老姓，今天只剩 twilight、twin、twice 几个孩子。tri- 是希腊/拉丁来的“三”，更常见。同一个“二”，有老姓，有新姓，有本土姓，有外来姓。

四、程度家族：姓“大、小、过、不足”的

这一族调音量。

  • macro- / micro-：macroeconomics, microscope
  • mega- / mini-：megaphone, miniskirt
  • hyper- / hypo-：hyperactive, hypothermia
  • over- / under-：overwork, underpaid
  • ultra-：ultrasound, ultramodern
  • out-：outnumber, outlive

hyper- 姓“过度”，hypo- 姓“不足”。一个往上冲，一个往下沉。程度姓，决定这个词是“过头了”还是“不够”。

五、时间家族：姓“先、后、再”的

这一族管先后。

  • ante- / pre- / fore-：antecedent, prehistoric, foretell
  • post-：postscript, postnatal
  • re-：redo, recycle
  • neo-：neolithic, neoclassical
  • paleo-：paleolithic, paleontology

ante- 姓“在……之前”，post- 姓“在……之后”。re- 姓“再一次”。时间姓，让一个词有了先后顺序。

六、关系家族：姓“一起、相互”的

这一族管人和人、物和物的关系。

  • co- / col- / com- / con- / cor-：cooperate, collaborate, combine, connect, correspond
  • sym- / syn-：sympathy, synthesis
  • inter-：interact, interpersonal

co- 家族是拉丁来的“一起”，sym- / syn- 是希腊来的“一起”。两个姓，同一个意思，来自两个不同的老家。

七、还有几个特别的姓

  • auto-：自己。automatic, autobiography
  • bio-：生命。biology, biography
  • tele-：远。telephone, television
  • pseudo-：假。pseudoscience
  • mal-：坏。malfunction, malice

这些姓不常组大族，但一出现，词义就定了调。

八、字父不是“意思”，是“框架”

最重要的一点：前缀不给你完整意思，它给你一个框架。

sub- 不是“潜艇”，是“在下面”。submarine 才是“在下面的海里的东西”。anti- 不是“战争”，是“反对”。antiwar 才是“反对战争”。

所以读单词，先认姓，再看名。姓定了方向，名填了内容。先知道它姓“下”，再看它叫什么；先知道它姓“反”，再看它反什么。

九、一句话

英文单词像人：有名，也有姓。 词根是名，前缀是姓。姓不决定你长什么样，但决定你归哪一家、站哪个位置、跟谁一伙。

pre- 姓“前”，post- 姓“后”，sub- 姓“下”，super- 姓“上”，anti- 姓“反”，co- 姓“一起”。你认得的姓越多，读陌生单词时，就越像在看一张有门牌号的街道图，而不是一堆散乱的字母。

字父，就是英文里的那些“姓”。 认了姓，名就好记了。
