单词故事：eternity

文/韩宝龙

2026年11月12日 08时23分11秒

单词故事

关于 eternity，信息整理如下：

🗣️ 发音

  • 英式：/ɪˈtɜːnəti/ (ih-TUR-nuh-tee)

  • 美式：/ɪˈtɜːrnəti/ (ih-TUR-nuh-tee)

  • 重音在第二音节。

  • 形容词：eternal（永恒的；无休止的）；副词：eternally（永恒地；没完没了地）；动词：eternize（使永恒，较少用）

📜 字父与词源

字父（前缀）：无。

词根：etern- = 永恒、永久（拉丁语 aeternus）。

后缀：-ity = 名词后缀，表示性质、状态。

整体：永恒的性质/状态 → 永恒、永世、无休止。

  • 拉丁语 aeternitas：永恒、永久。

  • 来自 aeternus（永恒的），可能由 aevum（年代、生命期）派生，更深与原始印欧语中表示“长久、生命”的词根有关；但词典对 aeternus 的构成有不同解释，不宜硬拆。

  • 经古法语/拉丁语进入英语，约 14世纪。

  • 同族词：

    • eternal：永恒的；没完没了的

    • eternally：永恒地

    • eternize：使永恒

    • aeon / eon（时代、永世）与 aevum 有远亲关系，但不完全同源

所以 eternity 的底层不是“时间很长”，而是 “没有尽头的时间状态”。

📖 英英解释（朗文/柯林斯）

  • 朗文：the state of existing for ever, without beginning or end；an extremely long time（大意：无始无终地存在的状态；极长的时间）。

  • 柯林斯：Eternity is time without an end, or a state of existence outside time, especially the state which some people believe they will pass into after death（大意：没有终点的时间，或时间之外的存在状态，尤指人死后进入的状态）。

📖 核心含义

  1. 永恒、永世：无始无终的时间状态。

    • for all eternity（永远）

    • throughout eternity（在永恒中）

  2. 极长的时间（口语/夸张）：an eternity = 很久很久。

    • It felt like an eternity.（感觉像过了一辈子。）

  3. （宗教）永生、来世：死后进入的永恒状态。

    • into eternity（进入永恒/去世）

  4. 永恒的事物/真理（抽象）：the eternities（永恒之事，较少）。

它比 forever 更正式、更哲学；比 infinity 更偏时间，infinity 可指空间/数量；比 timelessness 更常指无终点的延续；比 immortality 更偏时间状态，immortality 偏“不死”。

📖 历史上的著名用法

  • 《圣经》与神学：eternity 是核心词，指上帝的存在方式与信徒的永生。如《传道书》3:11“神造万物，各按其时成为美好，又将永生（eternity）安置在世人心里”。这里的 eternity 是“人心里对永恒的感知”。

  • 柏拉图与奥古斯丁：奥古斯丁区分 tempus（时间） 与 aeternitas（永恒）：时间是流动的，永恒是“同时的全体”。这是西方哲学中 eternity 最经典的讨论。

  • 莎士比亚与近代文学：eternity 常写死亡、爱情、誓言、审判的“永恒”维度。

  • 《悲惨世界》英译本可能语境：主教的信仰、冉阿让的临终、沙威面对“永恒”的秩序崩塌、公墓与死亡场景，都可能出现 eternity。

🌐 当代著名用法

  • for all eternity：永远

  • an eternity：很久很久

    • We waited an eternity for the bus.

  • into eternity：进入永恒；去世（委婉）

  • throughout eternity：在永恒中

  • eternal life / damnation：永生/永罚

  • eternal triangle：三角恋（固定说法，不是字面永恒）

  • eternally grateful：永远感激

  • eternally yours：永远属于你（书信结尾，旧式）

  • the eternity of…：……的永恒性

🔁 与近义词区别

词 含义 侧重点
eternity 永恒；永世；极长时间 偏无始无终的时间状态，正式/哲学/宗教
forever 永远 最口语、最通用
infinity 无限 偏空间/数量/数学，也可时间
timelessness 无时间性 偏超越时间，哲学/美学
immortality 不朽、不死 偏生命不灭
perpetuity 永久 法律/正式，偏“持续不断”
aeon / eon 永世、极长时间 偏时代/地质时间

关键：eternity 是“没有尽头的时间”；forever 最口语；infinity 偏数学/空间；immortality 偏不死；timelessness 偏超越时间。

📈 当下流行度

中高频。 宗教、哲学、文学、新闻中常见；an eternity、for all eternity、eternally grateful 都是稳定搭配。属于“认识且能准确使用”的词。

📚 在《悲惨世界》中的可能语境

  • 米里哀主教：他的信仰以 eternity 为背景——现世短暂，永恒才是尺度。

  • 冉阿让临终：他说“我死的时候，就是太阳升起的时候”，把死亡与 eternity 连在一起。

  • 沙威：他相信法律的秩序是“永恒”的；当冉阿让的宽恕打破它，他的 eternity 崩塌了。

  • 芳汀：她的苦难像 an eternity，而她的死亡被写成“进入永恒”。

  • 公墓与拉雪兹：墓碑、永恒、被遗忘，构成小说结尾的 eternity 意象。

  • 革命者：他们为“未来的永恒正义”而死，但雨果让 eternity 同时显得遥远而沉重。

✍️ 注释建议

eternity：n. 永恒，永世；极长的时间；（宗教）永生、来世。

字父：无；词根 etern- = 永恒（拉丁 aeternus / aeternitas）；后缀 -ity。

同族：eternal, eternally, eternize。

英英（朗文/柯林斯）：the state of existing for ever, without beginning or end; an extremely long time; time without an end, or a state outside time, especially after death.

搭配：for all eternity；an eternity；into eternity；throughout eternity；eternally grateful；eternal life/damnation。

与 forever/infinity/immortality 区别：eternity 偏“无始无终的时间状态”，正式/哲学/宗教；forever 最口语；infinity 偏数学/空间；immortality 偏不死。

在《悲惨世界》中，米里哀的信仰、冉阿让的临终、沙威的秩序崩塌、公墓场景，都可对应 eternity。

💎 一句话

eternity 是“没有尽头的时间”——不是“很久”，是“没有终点”。它从拉丁语“永恒”出发，核心是无始无终。在《悲惨世界》里，米里哀以 eternity 为尺度活着，沙威以为法律是 eternity，而冉阿让死时，太阳照进了 eternity。
