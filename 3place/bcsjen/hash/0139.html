《悲惨世界》阅读的SOP

文/韩宝龙

2026年10月27日 01时29分26秒

VERSION 0.1 2026年10月27日

《悲惨世界》每一章大约1000个单词左右，有的生词多一些，有的生词少一些，有的含义深奥、隽永一些有的简单直白一些，整体来说，各章之间还是差不多的，可以做一个相对标准的阅读模式，以提高阅读效率。

我计划用三遍阅读法来阅读。

第一遍：通读

也就是通读全章，这里要做的主要工作，就是注解生词。注解的原则是，只要不确定的，一律注解。按以前的经验，大概会注解30-100个生词。

同时，在通读时，还要标注重点句子。所谓的重点句子，就是有哲学价值、文学价值、幽默价值，或者其他我喜欢的。总之，我认为重点就是中调。

第二遍：精选五个生词

在注解的生词中，精选五个生词做深入研究。

所谓的深入研究，包括词源、词根、历史用法、和当代用法。

这五个生词会是当天的背诵单词，会记录在一张纸上。同时有电子版。同时用AI生成一句话以辅助记忆。

第三遍：朗读重点句子

对，就是朗读，并且录制下来重点句子，也就是第一遍通读时选的那些重点句子。

对于每一章，目前按这个三遍阅读法进行。后续有变化再迭代。

AI分析（DS）

你这个三遍阅读法，结构很清楚，而且抓住了精读的核心：先通、再深、后出声。整体可行，我提几个优化点，让它更稳、更可持续。

第一遍：通读 + 全注释

“不确定就注”是对的，但30–100个生词/章如果全部同等对待，第二遍会失焦。建议注释时顺手分三档：

  • 核心档：影响理解、反复出现、或像 install 那种“熟词僻义”——必注，标星。

  • 欣赏档：只出现一次但用得妙——注意思，标“赏”。

  • 过路档：纯生僻、专业词——注个意思即可，不要求记住。

重点句子除了标出来，每句写一行“为什么选它”：哲学、幽默、结构、用词、人物。否则第三遍朗读时容易忘了当初为什么选。

第二遍：精选五个生词

选词标准可以固定下来，避免每天凭感觉：

  1. 高频或复现率高；

  2. 多义/熟词僻义；

  3. 词源有趣、能串起同族词；

  4. 与本章主旨或人物有关；

  5. 搭配强、能直接用在写作里。

AI造句很好，但建议结合原文语境造一句，再另造一句当代生活句。一张纸+电子版没问题，纸上只写：单词、核心义、词源一句、两个例句、一个同族词。不要抄太多，否则复习负担重。

第三遍：朗读重点句子

朗读对。再加两个小动作：

  • 录音后回听一遍，标出停顿、重音、语气不对的地方；

  • 选一句仿写，换词不换结构。朗读是输入，仿写才是输出。

节奏与复习

  • 每章三遍不必同一天完成，可以通读当天、精词次日、朗读第三日，形成滚动。

  • 每周设一个回看日：翻一遍本周的“五词纸”和重点句，不重读全文。

  • 每章结束写三句话总结：本章讲了什么、一个人物变化、一个你记住的表达。

一句话

你的方法已经对了，现在要做的是给注释分档、给选词定标准、给朗读加回听和仿写。这样三遍不是重复三遍，而是通读、深挖、输出三层递进。
