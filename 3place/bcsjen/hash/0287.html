单词故事：try为什么有受审的意思？

文/韩宝龙

2026年11月14日 19时57分10秒

单词故事

一、一个看起来不讲理的词

try 最常用的意思是“尝试”：try again、try your best、try a new method。

但它在法律语境里又是“审判”：He was tried for murder.（他因谋杀受审。）The case will be tried next week.（案件下周开审。）

“尝试”和“审判”，看起来隔着很远。一个是你主动去试，一个是你被动被审。它们怎么会是同一个词？

答案在词源里：try 的本义不是“尝试”，而是“筛选、分辨”。 “尝试”和“审判”都是从“筛选/分辨”长出来的两条分支。

二、词源：try 的本义是“筛选”

try 源自古法语 trier，意为“挑选、筛选、分辨”。再往前，可能来自晚期拉丁语或通俗拉丁语中表示“捣碎、筛选”的词，与“把东西分开、挑出好的”有关。

核心动作很清楚：把混在一起的东西分开，辨明哪是哪。

这个动作可以用于谷物（筛掉糠）、用于布料（挑出次品）、用于人（分辨谁值得信任）、用于案件（分辨谁有罪）。“分辨”是根，“尝试”和“审判”是枝。

三、分支一：分辨 → 尝试

当你面对一个不确定的东西，你想知道它行不行、对不对、有没有用，你会怎么做？

你会试。

  • 试一个方法，是在“分辨”它有没有效。

  • 试一件衣服，是在“分辨”它合不合身。

  • 试一个人，是在“分辨”他靠不靠得住。

所以 try 的“尝试”义，本质是：通过做一次，来分辨结果。 它不是“随便做做”，而是“带着分辨目的的做”。

这也是为什么 try 和 test 经常可以互换：try a method / test a method，都是“通过做来分辨”。

四、分支二：分辨 → 审判

法律语境里的 try，逻辑完全相同，只是“分辨”的对象变了。

法庭审一个案子，做什么？

  • 听证据；

  • 问证人；

  • 辩论；

  • 分辨谁在说真话、谁有罪、该判什么。

这就是 try 的本义：分辨。

所以：

  • try a case = 分辨一个案子（审案）

  • try a person = 分辨一个人是否有罪（审人）

  • be tried for murder = 因谋杀被“分辨”（受审）

它不是“尝试审判”，而是“通过审理来分辨”。法庭不是在“试试看”，是在“辨明真相”。

五、为什么是“受审”，不是“审判”？

try 作“审判”时，既是主动的，也是被动的：

  • 法官 tries 案件（主动：审案）

  • 被告 is tried（被动：受审）

中文里“审判”偏主动，“受审”偏被动。英语 try 不分，因为它的核心是“分辨”这个动作本身：谁在分辨、谁被分辨，由句法决定，不由词义决定。

  • The court tried him.（法庭审他。）

  • He was tried by the court.（他被法庭审。）

同一个 try，主动句是“审”，被动句是“受审”。

六、这条语义链的其他站

从“筛选/分辨”出发，try 还长出了别的意思：

含义 逻辑
尝试 通过做来分辨
审判/受审 通过审理来分辨
考验、磨炼 用困难来“分辨”一个人的品质
试用 通过使用来分辨是否合适
试图、努力 带着分辨目的去行动

try 的“考验”义也是同一逻辑：trying times（艰难时世）——困难在“分辨”人。a trying experience（磨人的经历）——经历在“筛选”你的承受力。

七、和《悲惨世界》的关系

try 在《悲惨世界》里出现时，往往不是“尝试”，而是“审判/受审”：

  • 冉阿让在阿拉斯法庭受审（was tried）——法庭要“分辨”他是不是冉阿让。

  • 尚马秋受审（was tried）——法庭要“分辨”他是不是冉阿让，结果分辨错了。

  • 芳汀被审判（tried）——沙威要“分辨”她有没有“违法”，却不分辨谁先动手。

  • 沙威的整个职业，就是“分辨”谁有罪、谁该被追捕。

雨果让你看见：法庭的 try，常常不是在“分辨真相”，而是在“分辨身份、阶级、体面”。 冉阿让被 tried，不是因为他偷了什么，而是因为他是“苦役犯”；芳汀被 tried，不是因为她做了什么，而是因为她是“底层女人”。

try 的本义是“分辨”，但制度里的 try，常常分辨错了。

八、一句话

try 的“受审”，不是从“尝试”引申出来的，而是和“尝试”并列，都从“筛选/分辨”这个本义长出来。 尝试是“通过做来分辨”，审判是“通过审理来分辨”。同一个根，两条枝。

try 的灵魂是 “分辨”——分辨方法行不行，分辨人有没有罪，分辨衣服合不合身。你试，是在分辨；法庭审，也是在分辨。 只是法庭的分辨，常常带着权力、偏见和阶级。
