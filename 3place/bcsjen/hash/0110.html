单词故事：rumour

文/韩宝龙

单词故事

关于 rumour（美式拼写 rumor），信息整理如下：

🗣️ 发音

  • 英式：/ˈruːmə(r)/ (ROO-muh)
  • 美式：/ˈruːmər/ (ROO-muhr)
  • 复数：rumours / rumors
  • 形容词：rumoured / rumored（传闻的）

📜 词根与词源

rumour 的核心是 “噪声、众口相传的声音”。

  • 拉丁语 rumor：意为“嘈杂声、低语、传闻、公众舆论”。
  • 古法语 rumor / rumour：约 14世纪 进入中古英语，拼写逐渐固定为 rumour。
  • 美式英语后来简化为 rumor，与 color/colour、honor/honour 同一类拼写差异。
  • 同族词：rumored（据传的）、rumormonger（散布谣言者）、rumouring（散布传闻）。

📖 核心含义

  1. 传闻、谣言：未经证实、在人群中流传的说法。
    • There is a rumour that...：有传闻说……
    • rumours of war：战争传言
    • spread a rumour：散布谣言
  2. 不可数用法：传闻本身。
    • Rumour has it that...：据传……
  3. 可数用法：一条条传闻。
    • deny the rumours：否认传闻

📖 历史上的著名用法

1. 莎士比亚《亨利四世》第二部分（1598） 开场人物就叫 Rumour，他自述：

“Rumour is a pipe / Blown by surmises, jealousies, conjectures…” （传闻是一支笛子，由猜疑、嫉妒、臆测吹响……）

莎士比亚把 Rumour 拟人化，写成制造战争恐惧、搅乱人心的力量。这是英语文学中关于“谣言”最著名的段落之一。

2. 《圣经》与宗教语境 英文圣经中 rumour 常译希伯来语/希腊语中“风声、消息、坏消息”。如《马太福音》24:6 “你们也要听见打仗和打仗的风声”，钦定本用 “rumours of wars”。这使 rumour 带上“末世预兆”的色彩。

3. 19世纪小说与政治 在狄更斯、雨果、巴尔扎克笔下，rumour 常是城市底层与政治动荡的传播机制：街垒未起，传言先行；真相未明，恐慌已散。

🌐 当代的著名用法

1. 新闻与政治 - deny a rumour：否认传闻 - fuel rumours：助长传言 - dismiss rumours：驳斥谣言 - rumours are circulating：传言正在流传 - there are rumours that...：有传言说……

2. 社交媒体与“谣言经济” - spread misinformation and rumours：传播错误信息与谣言 - rumour mill：谣言工厂/传言圈 - internet rumour：网络谣言

3. 固定表达 - Rumour has it that…：据传…… - the rumour mill：流言蜚语的传播渠道 - a rumour is going around：有个传言在流传

4. 与 gossip 的区别 | 词 | 含义 | 侧重点 | |—|—|—| | rumour | 传闻、谣言 | 未经证实的信息，不一定关于私生活 | | gossip | 闲话、八卦 | 关于他人私生活的闲聊，常带贬义 | | hearsay | 道听途说 | 法律/正式语境，强调“非直接证据” |

rumour 可以是政治、战争、商业、名人等任何领域的未证实消息；gossip 更偏私人八卦。

📚 在《悲惨世界》中的可能语境

在英文版《悲惨世界》中，rumour 可能用于： - 冉阿让的身份：关于“马德兰先生究竟是谁”的传闻。 - 芳汀的遭遇：小镇上关于她的流言蜚语，加速她被社会抛弃。 - 街垒战前：巴黎流传的政治传言、军队动向。 - 沙威：他依赖情报与传言追捕冉阿让。

✍️ 注释建议

rumour（美式 rumor）：n. 传闻，谣言；v. 据传。
词源：拉丁 rumor（嘈杂声、传闻）→ 古法语 → 中古英语。
搭配：rumour has it that；deny/spread/fuel rumours；the rumour mill。
与 gossip 区别：rumour 偏“未证实消息”，gossip 偏“私人闲话”。

💎 一句话

rumour 从“人群中的嘈杂低语”出发，核心是“未经证实、却已经传开的声音”。 它可以是战争的风声、名人的绯闻、街头的流言；莎士比亚把它写成吹笛人，当代人把它写进“谣言工厂”。当你读到它时，可以想象 一群人交头接耳、消息越传越走样——那就是 rumour。
