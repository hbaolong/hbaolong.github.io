从“cunning”到“shrewd”，英语中的那些“精明”

一、一个词，两条路

“精明”在中文里是个好词，至少不算坏词。我们说一个人精明，多半是夸他脑子清楚、会算账、不吃亏。但英语里，“精明”不是一个词，而是一条谱。谱的一端是prudent（审慎），另一端是cunning（狡猾）。中间还站着shrewd、canny、astute、crafty、calculating、wily、sly。

它们都表示“脑子快、会算计”，但算计的目的、底线和后果完全不同。用错一个词，一个人就从“精明的商人”变成“阴险的恶棍”。

二、谱的右端：cunning 与它的同伙

Cunning 是这条谱上最靠“恶”的一头。它的核心不是“聪明”，而是用聪明去骗、去利用、去绕开规则。

  • cunning：狡猾，善欺骗和利用别人的弱点。
  • crafty：诡计多端，善耍手段。
  • wily：狡黠，老狐狸式，靠经验绕人。
  • sly：偷偷摸摸地狡猾，不正面来。
  • calculating：精于算计，每一步都为自身利益。
  • scheming：爱谋划，常带阴谋。
  • devious：不正直，绕弯子使坏。
  • unscrupulous：无底线，不择手段。

这些词共享一个画面：一个人躲在暗处，看着别人的弱点，盘算怎么从中取利。 他不创造价值，他转移价值。他不和别人合作，他利用别人。

《悲惨世界》里的德纳第，就是这条谱的活标本。他看芳汀的绝望，不算“她需要帮助”，而算“她还能榨出多少”。他看珂赛特，不算“一个孩子”，而算“一个免费劳动力”。他的精明是刀，用来割别人。

三、谱的左端：shrewd 与它的邻居

Shrewd 是这条谱上最靠“中性偏褒”的一头。它的核心是判断准、看人清、会算账，但不一定使坏。

  • shrewd：精明，判断准，会算实际利益。
  • canny：精明，不轻易上当，小商人气质。
  • astute：敏锐精明，偏正式，洞察力强。
  • prudent：审慎，会权衡后果，为自己留后路。
  • judicious：有判断力，明智。
  • sagacious：睿智，有远见。
  • businesslike：务实，讲效率，按规则来。
  • hardheaded：冷静务实，不讲情面但不算坏。

这些词共享另一个画面：一个人站在明处，看清局面，算清代价，做出对自己有利但不伤害他人的决定。 他不骗人，不绕规则，不利用弱点。他只是不让自己吃亏。

《悲惨世界》里的斯考夫莱尔，就是这条谱的样本。他是车行老板，冉阿让找他买马车。他看冉阿让着急，会算“这单生意能赚多少”，但他不会伪造、不会勒索、不会落井下石。他的精明是算盘，用来算账，不是用来割人。

四、中间地带：shrewd 的两面性

Shrewd 之所以是这条谱的枢纽，是因为它可以往两边滑。

  • 说一个商人 shrewd，是夸他判断准、会做生意。
  • 说一个政客 shrewd，可能是夸他老练，也可能是暗示他太会算。
  • 说德纳第 shrewd，不够；必须加 cunning 或 unscrupulous，才能写出他的恶。

Shrewd 本身不带道德判断，它只描述“算得准”。 算得准用来做好事，是马德兰；算得准用来做坏事，是德纳第。所以雨果写德纳第，不会只用一个 shrewd；他会让 shrewd 和 cunning、calculating、vicious 站在一起，让读者看见“算得准”如何变成“算得狠”。

五、中文“精明”为什么不够用

中文的“精明”覆盖太广。我们说一个人精明，可能是夸，也可能是贬，全靠语气和语境。英语不给你这个模糊空间：你选哪个词，就决定了这个人是“会算账”还是“会害人”。

  • 斯考夫莱尔是 shrewd，不是 cunning。
  • 德纳第是 cunning，不只是 shrewd。
  • 米里哀主教两者都不是。他不算账，他给。

这就是英语“精明”词谱的伦理重量：它不让你含糊。 你要么说这个人 prudent，要么说这个人 crafty；你要么说这个人 canny，要么说这个人 wily。每个词都在替你表态。

六、一条谱，三种人

把这条谱拉直，可以看见三种人：

第一种：prudent / judicious / sagacious
他们精明，是为了不犯错、不走错路、不辜负责任。他们的精明是智慧。

第二种：shrewd / canny / astute / businesslike
他们精明，是为了不吃亏、抓住机会、把事做成。他们的精明是能力。

第三种：cunning / crafty / calculating / wily / unscrupulous
他们精明，是为了利用别人、绕开规则、把别人的东西变成自己的。他们的精明是武器。

《悲惨世界》里，米里哀属于第一种，斯考夫莱尔属于第二种，德纳第属于第三种。雨果没有用一个“精明”把他们混在一起；他用不同的词，让读者看见精明的三种灵魂。

七、一句话

从 cunning 到 shrewd，英语把“精明”拆成了一条伦理光谱。 一端是“我会算，但我不害你”；另一端是“我会算，而且我算的就是你”。中文的“精明”可以含糊，英语不让你含糊。你选哪个词，就决定了你看见的是算盘，还是刀。
