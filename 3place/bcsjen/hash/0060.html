单词故事：improbable

文/韩宝龙

2026年10月6日 12时23分40秒

单词故事

关于 improbable，信息整理如下：

🗣️ 发音

  • 英式：/ɪmˈprɒbəbl/ (im-PROB-uh-buhl)
  • 美式：/ɪmˈprɑːbəbl/ (im-PRAH-buh-buhl)
  • 重音在第二音节。
  • 副词：improbably /ɪmˈprɒbəbli/
  • 名词：improbability /ɪmˌprɒbəˈbɪləti/

📜 词根与词源

improbable = im-（不）+ probable（可能的）。

  • probable 源自拉丁语 probabilis，意为“可证明的、可信的、可能的”。
  • 其词根是 probare，意为“测试、证明、赞同”。这个词根也衍生出：
    • prove（证明）
    • proof（证据）
    • probation（试用期，原义“检验期”）
    • probate（遗嘱认证）
    • probe（探查，可能相关）
  • im- 是 in- 在 p 前的同化形式，表否定。
  • 所以 improbable 字面意思是 “不能被证明为可能的”，引申为 “不太可能的、未必发生的”。

同族词：probable（可能的）、probably（很可能）、probability（概率）、improbability（不大可能）、improbably（不大可能地）。

📖 历史上的著名用法

1. 柯南·道尔《四签名》（1890） 福尔摩斯最著名的台词之一： > “When you have eliminated the impossible, whatever remains, however improbable, must be the truth.” > （当你排除了所有不可能，剩下的无论多么难以置信，都必定是真相。）

这里的 improbable 是推理的核心概念：它不等于“不可能”，而是“可能性极低”。福尔摩斯提醒我们：低概率不等于零概率。

2. 莎士比亚《哈姆雷特》（1601） 哈姆雷特在剧中多次使用 improbable 或其变体，表达对鬼魂、阴谋和人性反常的怀疑。这个词在莎士比亚笔下，常与 “看似荒谬却可能为真” 的认知张力有关。

3. 19世纪科学文献 达尔文在《物种起源》中讨论“自然选择”时，常面对“这么复杂的器官怎么可能通过偶然变异形成”的质疑。他用 improbable 来描述那些 看似极不可能、但在漫长时间和大量试错中成为可能 的事件。这体现了该词在科学语境中的关键地位：低概率事件在足够长的时间尺度上，几乎是必然的。

4. 简·奥斯汀《傲慢与偏见》（1813） 奥斯汀笔下的人物常用 improbable 来评价婚姻、继承和社交中的“意外”。它带有一种 理性的怀疑，但不彻底否定。

🌐 当代的著名用法

1. 日常与新闻（最常用） 表示“不太可能发生”： - “It is highly improbable that he will resign.”（他辞职的可能性极低。） - “An improbable comeback”（一场不可思议的逆转）——常用于体育报道。 - “The story sounds improbable, but it’s true.”（这故事听起来不太可能，但却是真的。）

2. 科学与统计学 improbable 是概率语言的核心词汇： - “Statistically improbable”（统计上不太可能） - “An improbable event”（低概率事件） - 在量子力学、进化生物学、金融风险模型中，improbable 常与 impossible 严格区分：前者是概率极低，后者是概率为零。

3. 体育与娱乐 体育新闻尤其爱用 improbable： - “The team’s improbable run to the finals”（球队不可思议地闯入决赛） - “An improbable victory”（一场难以置信的胜利） - 它强调 赛前几乎没人看好，但结果发生了。

4. 与 impossible、unlikely 的区别

词 含义 概率
impossible 不可能 0%
improbable 不太可能，可能性极低 接近 0%，但不为 0
unlikely 不太可能 低于 50%，较口语
probable 很可能 高于 50%

improbable 比 unlikely 更正式、更强烈，常用于 “虽然可能性极低，但并非绝无可能” 的语境。

📚 在《悲惨世界》中的可能语境

在英文版《悲惨世界》中，improbable 可能用于： - 沙威：他无法接受冉阿让的“改过自新”，因为在他看来，一个苦役犯变成善人，是 improbable 的。 - 米里哀主教：他的行为在世俗眼中是 improbable 的——一个主教放弃舒适、欢迎所有人。 - 冉阿让的逃亡：他的多次脱险，在旁人看来是 improbable 的。 - 马吕斯与珂赛特的爱情：在阶级鸿沟和革命动荡中，他们的结合显得 improbable。

💎 总结

improbable 从拉丁语 “不能被证明为可能” 出发，核心始终是 “可能性极低，但不等于零”。它比 unlikely 更正式，比 impossible 更留有余地。当你读到这个词时，可以想象一个 几乎不可能发生、却偏偏发生了 的事件——那就是 improbable。
