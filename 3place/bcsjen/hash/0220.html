单词的‘态度’，ness一下吧

文/韩宝龙

2026年11月7日 18时11分53秒

-ness 是英语里最“老实”的名词后缀之一：它几乎不改变词根的意思，只做一件事——把形容词变成抽象名词，表示“性质、状态、程度”。

1. 词性改变：形容词 → 名词

  • kind（善良的）→ kindness（善良）

  • dark（黑暗的）→ darkness（黑暗）

  • happy（快乐的）→ happiness（幸福）

  • weak（虚弱的）→ weakness（虚弱；弱点）

  • tired（疲倦的）→ tiredness（疲倦）

  • willing（愿意的）→ willingness（意愿）

  • prepared（准备好的）→ preparedness（准备状态）

它也可以加在分词后：unexpectedness（意外性）、forgiveness（宽恕，来自 forgive）。少数从名词/动词来：wilderness（荒野）、witness（证人/见证）、business（事务/生意）。

2. 语义改变：只加“状态/性质”，不换核心

  • dark 是“黑的”，darkness 是“黑的状态”。

  • kind 是“善良的”，kindness 是“善良这种性质”，也可指“一个善举”（a kindness，可数）。

  • weak 是“弱的”，weakness 是“虚弱”，也可指“弱点/癖好”（a weakness for chocolate）。

核心意思不变，变的是“把它当性质/状态来看”。

3. 语法特点

  • 通常不可数：darkness, happiness, kindness。

  • 但有些可可数化，表示具体事例/种类：a kindness（一个善举）、a business（一家企业）、a witness（一个证人）。

  • 可加 a 表示“一种”：a strange kindness。

  • 一般不加复数，除非语义专门化：businesses, witnesses。

4. 拼写规则

  • y 变 i：happy → happiness；busy → business；lonely → loneliness。

  • 一般直接加：kind → kindness；dark → darkness；weak → weakness。

  • 以 e 结尾通常保留：pure → pureness（较少，常用 purity）；sincere → sincereness（少）；更常见 tender → tenderness。

  • dry → dryness（保留 y）；shy → shyness。

  • 双写不常见：fat → fatness（不双写 t）。

5. 语体与能产性

  • -ness 是本土日耳曼后缀，高度能产：几乎任何形容词都能加，口语、学术、文学都能用。

  • 它比 -ity 更“日常”、更“直接”：

    • happy → happiness（常用）

    • possible → possibility（拉丁 -ity，不能产）

    • real → reality（不是 realness，虽然 realness 也存在，但少见）

  • -ity 多固定在拉丁借词里，不能随便造；-ness 可以临时造词，如 awkwardness, blissfulness, thoughtfulness。

6. 与相关后缀的区别

后缀 例 侧重点
-ness kindness, darkness 性质/状态，本土、能产、通用
-ity reality, possibility 性质/状态，拉丁来源、正式、多固定
-th truth, warmth, depth 性质/状态，古英语残留，数量少
-dom freedom, kingdom 状态/领域/集体
-ship friendship, leadership 身份/关系/状态
-hood childhood, brotherhood 身份/时期/集体
-ment movement, government 行为/结果，拉丁来源
-tion action, creation 行为/过程/结果，拉丁来源

-ness 最“透明”：kindness 就是“kind 的性质”；darkness 就是“dark 的状态”。它不添加额外意义，也不改变词根。

7. 在《悲惨世界》阅读中

你读的英文版里，-ness 高频出现，常把形容词变成可讨论的“性质”：

  • darkness：巴黎黑夜、下水道、苦役场。

  • kindness：米里哀的善、冉阿让的善举。

  • weakness：芳汀的脆弱、人的弱点。

  • sadness / loneliness / bitterness / tenderness / harshness / emptiness：人物心理与处境。

  • willingness：冉阿让的选择。

  • forgiveness：宽恕的主题。

看到 -ness，先判断：它把哪个形容词变成了“性质/状态”；再看是否可数化（a kindness = 一个善举）。

一句话

-ness 不改变词根的意思，只把“形容词”变成“性质/状态名词”。 它是最透明、最能产的名词后缀：kind → kindness，dark → darkness，weak → weakness。它和 -ity 意思相近，但 -ness 更本土、更日常、更能造新词；-ity 更正式、更固定、多来自拉丁语。
