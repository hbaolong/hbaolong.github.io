Le bagne /lə baɲ/

一、词性与语法

• 阳性名词（nom masculin）

• 定冠词：le（阳性单数）

• 复数：les bagnes

二、发音

部分 音标 说明

le /lə/ 弱读音节，类似汉语“勒”但更轻

bagne /baɲ/ /b/ + /a/ + /ɲ/（舌面硬腭鼻音，类似汉语“尼亚”快速合音）

整词：/lə baɲ/，重音在末音节。

注意：/ɲ/ 这个音在法语中不常见，发音时舌面中部抬起贴住硬腭，气流从鼻腔冲出，类似西班牙语 ñ 或意大利语 gn。汉语中没有完全对应的音，近似“nia”快速连读。

三、词源

• 源自意大利语 bagno（意为“浴室”）

• 意大利语 bagno → 法语 bagne

• 词义演变链条：

浴室 → 土耳其式监狱（奥斯曼帝国将囚犯关押在浴场建筑中） → 苦役犯监狱 → 泛指任何强迫劳役的监禁场所

这个演变很有意思：从“清洗身体的地方”变成了“清洗罪恶的地方”——同一个空间，从净身转为惩罪。

四、核心含义

  1. （历史）苦役犯监狱，划船苦役场（核心义） • 特指法国历史上设置在港口（尤其是土伦 Toulon、布雷斯特 Brest、罗什福尔 Rochefort）的强制劳役监狱，囚犯被锁在船上划桨或从事港口重体力劳动。

    • 1791 年法国废除划船苦役后，bagne 转而指陆地上的苦役犯监狱。

  2. （引申）地狱般的处境，苦役般的生活 • 比喻义，形容极端艰苦、毫无自由的生存状态。

五、在《悲惨世界》中的分量

Le bagne 是冉阿让人生的起点，也是贯穿全书的隐形重力场。

• 冉阿让因偷一块面包被判五年苦役，因四次越狱累加到十九年——他在 bagne 里度过了十九年。

• Bagne 在书中不仅是一个地点，更是一种烙印：冉阿让的黄色护照上写着“前苦役犯”，这张纸跟随他一生，随时可以将他打回原形。

• 雨果用 bagne 作为社会不公的终极象征：一个饥饿的人偷面包，社会给他的回应不是食物，而是锁链和划桨。

六、同族词与相关词汇

词 词性 含义

bagnard n.m. 苦役犯

bagne n.m. 苦役犯监狱

forçat n.m. 划船苦役犯（更古老的词，与 galère 划桨船相关）

galère n.f. 划桨船；苦役（俗语 c’est une galère = 这真是受罪）

travail forcé n.m. 强迫劳役

七、一句话总结

Le bagne 是法国历史上最黑暗的空间——从意大利语的“浴室”一路滑向“地狱”，雨果用它来质问一个社会：当一个人饿了，你给他面包还是锁链？
