单词故事：delirious

文/韩宝龙

2026年11月10日 22时51分37秒

单词故事

关于 delirious，信息整理如下：

🗣️ 发音

  • 英式：/dɪˈlɪriəs/ (dih-LIR-ee-uhs)

  • 美式：/dɪˈlɪriəs/ (dih-LIR-ee-uhs)

  • 重音在第二音节。

  • 名词：delirium（谵妄；精神错乱；极度兴奋）；副词：deliriously（神志不清地；极度地）

📜 字父与词源

字父（前缀）：de- = 离开、偏离。

词根：lir- = 犁沟（拉丁语 lira，指犁出的沟垄）。

后缀：-ious = 充满……的、具有……性质的。

整体：偏离犁沟的 → 偏离正轨的 → 神志错乱的、谵妄的。

  • 拉丁语 delirare：由 de-（离开）+ lira（犁沟）构成，字面意为 “偏离犁沟、走歪了”。

  • 古罗马人用“犁地走歪”比喻 “头脑偏离正轨”，于是 delirare 引申为“发疯、说胡话”。

  • delirium 是医学/拉丁名词；delirious 是形容词，约 18世纪 进入英语。

  • 同族词：

    • delirium：谵妄；精神错乱；极度兴奋

    • deliriously：神志不清地；极度地

    • deliriant：致谵妄的（药物/毒物，专业）

    • deliration：谵妄（古/少用）

所以 delirious 的底层不是“发疯”，而是 “犁地走歪了”——头脑偏离了正常轨道。

📖 核心含义

  1. 谵妄的、神志不清的：因高烧、疾病、药物、酒精等导致意识混乱、说胡话。

    • delirious with fever（因高烧而谵妄）

    • a delirious patient（谵妄的病人）

  2. 极度兴奋的、发狂的：因喜悦、激动、狂热而失去常态。

    • delirious with joy（欣喜若狂）

    • a delirious crowd（狂热的群众）

  3. （口语）极度快乐的、忘乎所以的：

    • deliriously happy（快乐得发狂）

  4. （古）精神错乱的、疯狂的。

它比 confused 重得多，偏病理性意识混乱；比 feverish 更偏神志不清，不只是“发烧”；比 ecstatic 更带失控、失去常态的意味；比 hysterical 少一点“情绪爆发”，多一点“意识偏离”。

📖 历史上的著名用法

  • 医学传统：delirium 是医学核心术语，指急性意识混乱状态。19世纪医学文献常写 delirious with fever、delirium tremens（酒精戒断性谵妄）。

  • 莎士比亚与近代文学：delirious 常写高烧、疯狂、狂热、爱情。它不只是“糊涂”，而是整个人偏离常态。

  • 19世纪小说：常写临终谵妄、高烧说胡话、狂喜失态。在《悲惨世界》英译本中，芳汀临终、冉阿让在极度疲惫/焦虑中、街垒上的狂热，都可能用 delirious。

🌐 当代著名用法

  • delirious with fever / pain / exhaustion：因高烧/疼痛/疲惫而谵妄

  • delirious with joy / excitement：欣喜若狂/兴奋得发狂

  • deliriously happy：快乐得发狂

  • a delirious crowd / atmosphere：狂热的群众/气氛

  • delirium：谵妄；极度兴奋

    • delirium tremens (DTs)：酒精戒断性谵妄

  • deliriously：神志不清地；极度地

    • deliriously funny（极其好笑）

🔁 与近义词区别

词 含义 侧重点
delirious 谵妄的；神志不清的；极度兴奋的 偏意识偏离常态，可病理可狂喜
confused 困惑的 最通用，程度轻
feverish 发烧的；狂热的 偏发烧/焦躁，不一定意识混乱
hallucinating 产生幻觉的 偏感官幻觉
ecstatic 狂喜的 偏极度喜悦，不一定失控
hysterical 歇斯底里的 偏情绪失控爆发
incoherent 语无伦次的 偏表达不清，不一定意识混乱

关键：delirious 是“脑子偏离正轨”；confused 只是“糊涂”；ecstatic 是“狂喜”；hysterical 是“情绪失控”。

📈 当下流行度

中高频。 医学、文学、新闻、日常都用；delirious with fever、deliriously happy、delirium 都是稳定搭配。属于“认识且能准确使用”的词。

📚 在《悲惨世界》中的可能语境

  • 芳汀：临终前高烧、谵妄，delirious 是最贴切的词之一。

  • 冉阿让：在尚马秋案件前夜、下水道中，极度疲惫与焦虑可近乎 delirious。

  • 街垒战：狂热、恐惧、疲惫交织，人群可写成 delirious。

  • 沙威：面对宽恕时，他的世界观崩塌，近乎一种冷性的 delirium。

  • 米里哀主教：他不 delirious；他清醒、平静、开门。

✍️ 注释建议

delirious：adj. 谵妄的，神志不清的；极度兴奋的，发狂的。

字父：de- = 离开；词根 lir- = 犁沟（拉丁 lira）。字面“偏离犁沟”→ 头脑走歪。

同族：delirium, deliriously, deliriant。

搭配：delirious with fever/joy；deliriously happy；a delirious crowd；delirium tremens。

与 confused/ecstatic/hysterical 区别：delirious 偏“意识偏离常态”，可病理可狂喜。

在《悲惨世界》中，芳汀临终、冉阿让极度疲惫、街垒狂热，都可写成 delirious。

💎 一句话

delirious 是“犁地走歪了”——头脑偏离了正常轨道：高烧时说胡话，狂喜时忘乎所以。它从拉丁语“偏离犁沟”出发，核心不是“疯”，而是意识脱轨。在《悲惨世界》里，芳汀临终的 delirious，就是一个人被苦难推离了意识的轨道。
