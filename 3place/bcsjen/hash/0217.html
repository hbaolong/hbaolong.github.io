单词故事：拉丁语是如何进入英语的？

文/韩宝龙

2026年11月7日 18时00分12秒

单词故事

英语属于日耳曼语族，但它的词汇却有一大半来自拉丁语或经由法语而来的拉丁语。一个英语母语者日常说话，可能每三个词里就有一个藏着拉丁语的根。这不是偶然，而是一千多年里，好几波“拉丁语移民”先后进入英语的结果。

第一波：罗马人来了，但没留下多少词

公元43年，罗马军团征服不列颠，统治了近四百年。按理说，这是拉丁语进入英语最直接的机会。但奇怪的是，古英语里留下的拉丁借词并不多，大概只有一两百个，而且多是生活底层词：

  • street（街道）← 拉丁 strata（铺好的路）

  • wall（墙）← 拉丁 vallum（壁垒）

  • wine（葡萄酒）← 拉丁 vinum

  • cheese（奶酪）← 拉丁 caseus

  • kitchen（厨房）← 拉丁 coquina

  • mile（英里）← 拉丁 milia（千步）

  • bishop（主教）← 拉丁 episcopus

  • church（教堂）← 希腊语 kyriakon，经拉丁语进入

这些词很具体：路、墙、酒、奶酪、厨房、里程。罗马人留下了城市生活、道路、酒和基督教，英语就借了这些词。但罗马人撤走后，拉丁语在不列颠基本消失了。

第二波：基督教来了，带来宗教词

公元597年，奥古斯丁到英格兰传教，基督教再次带来拉丁语。这一波借词集中在宗教和学术：

  • angel（天使）← 拉丁 angelus

  • disciple（门徒）← 拉丁 discipulus

  • martyr（殉道者）← 拉丁 martyr

  • psalm（诗篇）← 拉丁 psalmus

  • nun（修女）← 拉丁 nonna

  • priest（神父）← 拉丁 presbyter

  • school（学校）← 拉丁 schola

  • master（老师/主人）← 拉丁 magister

这一波让英语开始有了抽象词和教育词。但总量仍不算大。

第三波：诺曼征服——拉丁语“换了个包装”进来

1066年诺曼征服是英语词汇史上最大的转折。诺曼人说法语，而法语本身是拉丁语的“女儿”。于是，大量拉丁语词经由法语进入英语，不是直接借，而是“二手借”。

这一波借词覆盖了法律、政治、宗教、艺术、烹饪、贵族生活：

法律与政治：

  • justice ← 法语 justice ← 拉丁 justitia

  • government ← 法语 ← 拉丁 gubernare（掌舵）

  • parliament ← 法语 parlement ← 拉丁 parlare（说话）

  • court ← 法语 cour ← 拉丁 cohors（围栏）

  • crime ← 法语 ← 拉丁 crimen

  • punish ← 法语 punir ← 拉丁 punire

宗教：

  • religion ← 法语 ← 拉丁 religio

  • prayer ← 法语 priere ← 拉丁 precaria

  • saint ← 法语 ← 拉丁 sanctus

  • charity ← 法语 charité ← 拉丁 caritas

日常生活：

  • beef ← 法语 bœuf ← 拉丁 bos（牛）

  • pork ← 法语 porc ← 拉丁 porcus（猪）

  • mutton ← 法语 mouton ← 拉丁 multo（羊）

  • dinner ← 法语 disner ← 拉丁 disjejunare（打破斋戒）

有趣的是：活的动物用英语词（cow, pig, sheep），端上桌的肉用法语/拉丁词（beef, pork, mutton）。因为养猪的是英国农民，吃猪的是诺曼贵族。词汇的分层，就是阶级的分层。

这一波之后，英语的上层词汇几乎被拉丁语系“换血”。英语没有变成法语，但它的法律、政府、宗教、文化词汇，基本都姓了“拉丁”。

第四波：文艺复兴——学者直接搬拉丁语

16—17世纪，文艺复兴让英国学者重新迷上古典拉丁语。他们不再满足于“经法语转手”，而是直接从拉丁语借词，尤其是学术、科学、文学词汇：

  • education ← 拉丁 educatio

  • literature ← 拉丁 litteratura

  • science ← 拉丁 scientia

  • argument ← 拉丁 argumentum

  • fact ← 拉丁 factum

  • focus ← 拉丁 focus（炉灶→焦点）

  • virus ← 拉丁 virus（毒）

  • area ← 拉丁 area（空地）

  • data ← 拉丁 data（给的东西）

  • media ← 拉丁 media（中间的东西）

这一波词的特点是：拼写更接近拉丁原形，不像法语借词那样被“磨圆”。比如 fact 直接来自 factum，science 来自 scientia，data 直接保留拉丁复数。

第五波：科学革命与近代学术——拉丁语是“通用语”

17—18世纪，牛顿、林奈、笛卡尔等学者用拉丁语写作。英语科学词汇大量直接借拉丁语或拉丁化的希腊语：

  • gravity ← 拉丁 gravitas（重量）

  • momentum ← 拉丁 momentum（运动）

  • radius ← 拉丁 radius（射线）

  • formula ← 拉丁 formula（小形式）

  • species ← 拉丁 species（外观）

  • genus ← 拉丁 genus（种类）

  • vaccine ← 拉丁 vaccinus（牛的）

  • botany ← 拉丁 botanicus ← 希腊 botane（草）

这些词今天仍是科学、医学、法律的核心词汇。

第六波：现代英语——拉丁词根还在“造新词”

拉丁语不再作为口语使用，但它的词根和前缀仍是英语造新词的主要材料：

  • television：tele-（希腊语“远”）+ vision（拉丁 visio“看”）

  • telephone：tele- + phone（希腊“声音”）

  • automobile：auto-（希腊“自己”）+ mobile（拉丁 mobilis“可动的”）

  • computer：com-（一起）+ putare（计算）

  • internet：inter-（之间）+ net（英语本土词）

  • antibiotic：anti-（反）+ biotic（拉丁/希腊“生命的”）

  • democracy：demo-（人民）+ cracy（统治），希腊来源，经拉丁语进入

今天英语里新造的词，只要涉及科技、学术、正式文体，几乎都会动用拉丁/希腊词根。拉丁语没有死，它只是变成了英语的“零件库”。

拉丁语进入英语的三种方式

总结一下，拉丁语进入英语，主要有三条路：

  1. 直接借词：学者从拉丁语直接搬，如 fact, data, science。
  2. 经法语中转：诺曼法语把拉丁词“磨圆”后送进英语，如 justice, beef, charity。
  3. 词根造新词：用拉丁词根+前缀造现代词，如 television, antibiotic, computer。

一个词的故事：从 domus 到 domestic

以你熟悉的 domus（家）为例，看它如何进入英语：

  • 拉丁 domus（家）→ domesticus（家的）→ 英语 domestic（家庭的；国内的）

  • 拉丁 domina（女主人）→ 古法语 dame → 英语 dame（夫人；女爵士）

  • 拉丁 dominus（主人）→ dominari（支配）→ 英语 dominate（支配）

  • 拉丁 domus → dome（穹顶，像家的屋顶）

  • 拉丁 domus + con-（共同）→ condominium（共有公寓）

一个“家”，长出了家庭、夫人、支配、穹顶、公寓。这就是拉丁语在英语里的存在方式：不是作为一个外来词，而是作为一整套意义骨架。

一句话

拉丁语进入英语，不是一次“入侵”，而是一千多年的“分层沉积”：罗马人留下路和酒，基督教留下天使和学校，诺曼人留下法律和牛肉，文艺复兴留下科学和文学，现代英语则把拉丁词根当积木，继续造新词。英语的“日耳曼骨架”上，长满了“拉丁血肉”。你读的每一个正式英语句子，几乎都在同时使用这两套系统。
