So的主要用法

一.副词 so 作“如此地”、“这样地”、“那样地”讲，有时代替上文中有关形容词、名词和动词，译成“也”或“确实”

1.Why（is that） so ？为什么这样呢？

2.We say she studies very hard，and so she does.我们说她学习非常用功，而她确实如此。

二.连词so作“因而”、“所以”解

The door was locked. So he could not come in.门锁上了，所以他不能进来。

三.与so连用的一些常用词组

1.She does not speak English so well as you.她英语不如你说得好。

  1. So far from being true，the news is false.这消息绝非真实可靠，而是虚假捏造。（本句中用so是表示强调。）

  2. So far it has not happened.直到如今此事尚未发生。

4.I have read only two pages or so .我只读了两页左右。

5.You may borrow my electronic dictionary so long as you keep it clean.只要你把我的电子词典保持干净，你就可借用这本词典。

  1. So far as the noise is concerned，the colour TV set is out of order.就杂音来说，这台彩电发生故障了。

  2. As far as I know，he is so angry as not to be able to say a word.据我所知，他气得连一句话都说不出来。（句中 so … as 引出的不定式短语作结果状语用。）

8.He will have everything ready so as not to keep you waiting.他将做好一切准备，不使你等候。（ so as to 引出的不定式短语作目的状语用，也可用in order to代替。）

【注】 so that和so（或such）…that用法见下列专题。其他用法可查阅本书语法目录。
